#    どの機構も読んでいなかったので廃止された。 こちらは
#    **進行度の違う複数の写しと、その間を歩く一人の男**。 反復も決定論も主張しない。

#    ・大穴は次元の狭間に出現したポータル
#    ・狭間の近辺から別次元のアイテムが流れ込む = 遺物
#    ・大穴は日々拡大し、いずれ世界ごと呑まれる
#    ・破滅が近いほど街は栄える (誰も気づかない)

#  報酬は「凄まじく強力」。 頻度が 1/38 なので +30pt 級でも全体平均への寄与は
