# 吐く炎 `fire/fire-breath` (1.5 秒・ループ・160×116)

口元から右へ吹き出す炎の円錐。 口元は白く焼け、 進むほど膨らんで冷め、 上へめくれ、 縁から煙になる。 **向きのある炎・扇形に広がる炎の手本**。
ループなので全部を `t` から計算する。 部品 9 個・別々に描いて重ねた時の違いは 0.87%。
描く順: 煙 → 火の塊 (古い順に並べ替えて、 若い物を上に) → 縁のちぎれ → 中を走る光の筋 → 口元の噴射 → 火花 → 残り火 → 光。

## 部品

### `cone-billows`
円錐の本体。 火の塊 260 個/1.5 秒を、 角度 `e × spread` (`e` = −1〜1) へ速さ `speed × 0.75〜1.1` で飛ばす。 大きさ 3〜5.2 が `(0.75 + 1.6u)` 倍へ膨らむ。
**中心ほど長く熱い**: 寿命 = `0.42〜0.8 × (1 − 0.3|e|)`、 熱 = `u^1.5 × (0.85 + 0.2|e|) + 0.3e²`。 縁の塊は早く赤くなる。
抵抗 2 / 2.4・上へ −100 px/s² なので、 飛びながら減速して上へ曲がる。 古い塊から先に描く (若い = 熱い塊が上)。
単独で見ると: 丸い火の塊が扇形に並んだ雲。 口元が白、 先が赤。

### `cone-tear-tongues`
塊が寿命の 32% を過ぎると、 塊の上に炎の舌が生える (`tear`)。 塊は縮み、 舌が伸びる。 舌は後ろ (口の側) へ 40% 流す。 色の層は熱で 3 段 (`LAYERS` → `BACK_LAYERS` → `COOL_LAYERS`)。
**丸い塊 → 舌 → 煙、 と形を替えることで「燃えながら飛ぶ」になる**。 量は塊と同じくらい (7 万画素)。

### `cone-smoke`
縁の塊ほど煙になりやすい (確率 `0.2 + 0.4|e|`)。 大きい煙 (`big`)・濃さ 0.7 倍。 最初に描く (一番奥)。

### `edge-licks`
円錐の上下の縁から、 斜め後ろへめくれる舌 6 本 (`flameBlade`)。 円錐の輪郭を崩す。

### `roar-streaks`
円錐の芯を走る明るい線 70 本/1.5 秒。 速さ 330〜470・寿命 0.12〜0.26 秒・長さ 4〜9。 頭が白、 尾が黄〜金。 **勢い (速さ) を伝える部品**。 量は 1000 画素しかないが、 無いと煙のように見える。

### `lip-jet`
口元の白い噴射。 `flameBlade` 4 本 (長さ 42 / 32 / 30 / 20・角度 0 / −0.08 / +0.08 / 0)。 長さが `roar` (3 回/秒のうねり) で伸び縮みする。

### `sparks`
前へ飛んで落ちる火花 40 本/1.5 秒。

### `embers`
先端から浮く残り火 18 個。

### `light`
口元に半径 34 の強い光 (0.75) と白い芯。 円錐に沿って 8 px おきに、 先ほど大きい光。 全体に半径 96 の薄い光。

## 学べること
- **扇形の炎は、 角度 `e` を持った粒の集まり**。 `|e|` で寿命・熱・煙の出やすさを変えると、 芯が熱く縁が冷たい円錐になる。
- **形を時間で替える** (塊 → 舌 → 煙)。
- 向きを変えるには、 口元の位置と角度だけを変えればよい (`p.place` の `angle` でも回せる)。 **正面へ吹く炎**は、 この円錐を手前へ向けた物 = 中心から外へ広がる塊として組める。
