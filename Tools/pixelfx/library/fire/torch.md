# 松明 `fire/torch` (2 秒・ループ・72×120)

壁の金具に差した松明。 燃える所は共通の `burn` (舌 5 本・`height: 20`・`puffs: 10`・`licks: 5`・`smoke: 7`・`smokeSize: 2.3`・`embers: 7`・`glow: 1.25`)。 部品 9 個・違い 0.41%。

## 部品

### `burn:tongues`
手前の舌 3 本 (中央が高さ 100%・半幅 2.9)。

### `burn:tongues-back`
奥の舌 2 本。

### `burn:puffs`
舌先からちぎれる火の塊。

### `burn:licks`
舌先のちぎれ。

### `burn:plume-smoke`
煙の柱。

### `burn:puff-smoke`
火の塊の跡の煙。

### `burn:embers`
残り火。

### `burn:light`
光。

### `prop`
壁の板・柄・輪・油を染ませた布 (燃える所は焦げて、 割れ目に熾が点滅)。 布は `burn` の `mid` で、 舌の後・ちぎれの前に描く = 炎が布の中から出て見える。

## 学べること
- 道具と炎の重ね順は `burn` の `mid` で決める (舌 → 道具 → ちぎれと火の塊)。
