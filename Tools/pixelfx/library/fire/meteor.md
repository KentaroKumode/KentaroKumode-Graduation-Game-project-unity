# 隕石 `fire/meteor` (5 秒・1 回・272×232)

燃える岩が左上から彗星のように落ちて床に激突する。 白い閃光・放射の光条・投げ上げられる火球・立ちのぼる火と煙の柱・火花・残り火・燃える破片・岩と砂利・衝撃の輪・くぼみ。
**重い着弾の手本** (部品 33 個・この分類で一番多い)。 拍: **飛来 0〜0.62 秒** (岩 + 炎の尾 + ちぎれる火) → **着弾 0.62 秒** (決めのコマ) → **噴き上げ 〜1.7 秒** (火球と柱が上り、 煙へ) →
**余韻 〜4.7 秒** (煙の傘・くぼみが冷める・落ちた破片が小さく燃える)。 定数: `HIT = 0.62`・`FROM = [-112, -142]` (飛んでくる元)。
別々に描いて重ねた時の違いは 2.19% (煙が多く、 下の色に混ざるため)。 画素の量は、 煙 100 万・光 60 万・火の形 13 万。 **着弾の重さの大半は、 後から広がる煙の量**。

## 部品 (飛来)

### `meteor-rock`
岩の本体。 半径 6.5 のでこぼこした円 (角度のノイズで輪郭を 18% + 10% 揺らす)。 進む向きの面が白く焼け、 後ろは暗い岩に割れ目が光る。 1 px の暗い輪郭。

### `comet-tail`
岩の後ろへ流れる炎の舌 4 本 (`flameBlade`。 長さ 36 / 26 / 26 / 16・半幅 7〜8。 中央 1 本・左右にずらした 2 本・短い 1 本)。 長さと曲がりをノイズで揺らす。
**進む向きの逆へ舌を並べるだけで「飛んでいる」になる**。

### `meteor-light`
岩の周りの光 (半径 46 と、 芯の半径 12)。

### `approach-floor-light`
落ちる先の床の光だまり。 近づくほど広く強く (`(t / HIT)²`)。 **着弾の場所を先に教える予兆**。

### `tail/FIRE`
飛んでいる間、 岩の後ろへちぎれる火の塊 (1 フレームに最大 3 個・大きさ 3〜6)。 65% が大きい煙を残す。

### `tail/SMOKE`
ちぎれた火の跡の煙。 飛んだ跡が煙の筋になって残る (〜3.3 秒)。

### `tail/SPARK`
飛びながら散る火花。

### `tail/EMBER`
飛びながら落とす残り火。

## 学べること

- **着弾は「瞬間」と「ふくらみ」と「煙」の 3 層**。 瞬間 (閃光・光条・輪・火花) は 0.25 秒で終わる。 そのあと火球が 1 秒ふくらみ、 煙が 3 秒残る。
- **火が先、 煙が後**。 煙の傘は 0.15〜0.5 秒遅らせて出す。 同時に出すと、 火が煙に隠れる。
- **予兆は着弾点の床の光**。 飛んでくる物より先に、 落ちる場所が明るくなる。
- **着弾の後に「まだ燃えている物」を残す** (燃える破片 → 小さな火)。 画面が一度に空にならない。
- 火球の粒の大きさ (5〜9) は、 炎の柱の粒 (1.6〜6.5) より大きい。 **大きさで重さを出す**。
