# ヴェスカの大技 = 天与の剣 / 盾 / 指輪 — 2026-11-14〜15 作者と 1 つずつ詰めた形 (盾・指輪は「完成」。 剣は白飛びの後が未定)

効果は 1 本 `dicebound/tenyo-heavy` で、 `gift` (`sword` / `shield` / `ring`) と `part` (`flow` 見本用 / `charge` / `charged` / `heavy`) で出し分ける。
画面全体 (480×270)・原点は左上・金色・**1 秒 24 コマ** (作者: 全部 24 コマの方が良い)。 見本: `lab/tenyo_preview.py` → `Captures/fxlib/_tenyo/index.html`。
型は王・審判官と同じ: チャージ → 待機 (ループ) → 発動。 どれが来るかは、 待機の絵の場所で分かる (剣 = 敵の頭上・盾 = 敵の体・指輪 = 高い所の大きな輪)。

## 共通

- **チャージ**: 王のチャージと同じ 4 つ (画面じゅうから芯へ走る光の筋・渦を巻いて寄る粒・芯へ縮む輪・完了の瞬間に光が走る) を金で。 その間に形が出来ていく。
- **待機の間は画面を暗くする** (ゲームの側の処理・`idleDark`)。 完了の 0.35 秒で落ちて、 待機の間は保つ。
- **God rays** (`tenyo-rays.js`): weather/god-rays の写し。 出どころを画面のずっと上の外にして、 ほぼ平行に降り注ぐ。 段で塗る (淡い半透明は網点に潰れる)。
- **暗転は本物の真っ黒**。 絵 (日食・輪・注ぐ光) も一緒に消える。 黒の中に God rays だけが出て来る。
- **インパクトフレーム** (impacts/impact-frame) を下に敷き、 着弾の絵をその上に。
- 瓦礫 (岩・砂利・欠片) は出さない。 煙は小さい粒に分ける (`_scaled.js` の `puff`)。

## 作者の指摘で決まったこと (moves.md・weapons.md・foes.md に加えて)

- **この液晶の 5 つの色の段に、 1 段ずつ落ちるように色を選ぶ**。 明るい色ばかり並べると、 上の 2 段に潰れる (日食の冠)。
- **元の効果のぼかした光 (glow) は弱める** (`_scaled.js` の `glow`)。 網点のにじみになって、 形の段を覆う。
- **淡い半透明の重ね塗りは、 段で切ってべたの色で塗る** (Blessing の円錐・God rays)。
- **羽根のような細い物を広げて置く時は、 線の太さを画面の 1 ドットで決め直す** (`_feather.js`)。 枚数を増やして 1 枚を細く。 粒は、 飛ぶ範囲はそのまま、 粒だけ小さく。
- **行の途中にコメントを足さない** (1 行に詰めたコードの途中に `//` を入れると、 後ろが全部消える。 2 回壊した)。
