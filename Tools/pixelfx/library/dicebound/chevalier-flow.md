# シュヴァリエの大技の一連の流れ — 2026-11-14 作者が「これで ok」と決めた形

シュヴァリエ (`boss_layer5_hidden`) の大技。 作者の軸は **「キレとメリハリが最重要」**。 静 (暗い画面に鋭い光 1 つ) → 無 (真っ黒な一拍) → 一瞬 (一閃・黒が左右に割れる)。
効果は 3 本。 どれも画面全体 (480×270)・1 秒 8 コマ・鋼の色の組 (`lab/lcd_frames.mjs --ink steel`・一番暗い色は黒) で見て決めた。

| 順 | いつ | 効果 | 設定 | 尺 |
|---|---|---|---|---|
| 1 | シュヴァリエのチャージのターン | `dicebound/chevalier-charge` | 既定 | 2.75 秒 |
| 2 | プレイヤーの手番の間 | `dicebound/chevalier-charged` (ループ) | 既定 | 1.5 秒で 1 周 (12 コマ) |
| 3 | 大技のターン (待機の 0 / 6 コマ目から続ける) | `dicebound/chevalier-slash` | 既定 (`lead: 0.75`・`slant: 60`・`accel: 3000`・`face: "hard"`) | 1.75 秒 |

- 1・2 は原点がチャージの中心 (240,130) = 敵の足もと (240,196) の 66 上。 3 は原点が左上。
- 回る物が無いので、 3 は 1 本でよい。 待機の 0 / 6 コマ目 (長さの脈が同じ所) で入る (最大 0.6 秒待つ)。
- 通しの見本: `lab/chevalier_flow_preview.py` → `Captures/fxlib/_chevalier/flow.html`。 切り口の案の見比べ: `lab/chevalier_face_preview.py` → `face.html`。

## 効果の外でゲーム側がやること (暗幕の段取りが肝)

| 時刻 | 暗幕 |
|---|---|
| チャージ中 | 最初の 6 コマで 30% 暗く |
| チャージ完了 (13 コマ目) から 3 コマ | **かなり暗く** (85% 暗く = 明るさ 15%)。 きらめきは暗幕の上に描く |
| 待機 | そのまま |
| 大技の開始から 0.6 秒 (`lead × 0.8`・きらめきが消えた時) | **真っ黒** (100%・色 `#020308`) |
| 0.69 秒 (`timing(lead).cut` = `lead − 0.06`) | **暗幕を外す**。 ここからは効果が黒い 2 枚を自分で描いて動かす (同じ色) |

- **揺れ**: 割れ始め (`timing(lead).split` = `lead + 0.18`) の次のコマから `(4,0) (-3,2) (2,-2) (-2,1) (1,-1) (0,1)` ドット。
- 黒い 2 枚の色 (`color`) と、 暗幕 100% の色と、 色の組の一番暗い色を、 同じにすること。 ずれると、 暗幕を外したコマで黒の色が変わる。

## 部品と、 借りた元

| 効果 | 部品 | 借りた元 |
|---|---|---|
| charge | 吸い込まれる光の筋・渦を巻いて寄る粒・一点へ落ちる輪・小さいままの芯 | `explosions/implosion` (王・審判官と同じ) |
| charge / charged / slash の溜め | `glint()`: 1 ドット幅の細い十字 (横が長い)・根もとだけ 3 ドット・短い斜め・白い芯・薄い青白いブルーム | 切っ先のきらめき (`transitions/slash-wipe` の tip glint) を、 細い線で長く引いた |
| slash | 線に沿って裂ける一閃 (頭の後ろが一番太い・尾がほどける)・切っ先のきらめき・切り口に沿ってずれてから左右へ離れる 2 枚・継ぎ目の光・継ぎ目から両側へ噴く火花と削り屑 | `transitions/slash-wipe` の **2 太刀目と、 割れる所** |

## 作者の指摘で決まったこと

- チャージ完了で**画面全体をかなり暗く**し、 中心だけ**鋭く**光らせる (王 = 柔らかい十字・審判官 = 日輪 との差)。
- きらめきは線だけだとベタ塗りで光に見えない → **薄い青白いブルーム**。
- 「斜めに切ったなら、 黒い画面は**左右に離れる**はず」。 最初の版は slash-wipe の 1 太刀目 (黒で覆っていく刃) だけを使い、 刃の前にしか黒が無かった。 使うべきは 2 太刀目 (線で切って 2 枚に割れる)。
- 切り口の面を 1 ドットずつ等間隔に冷める段にすると、 作り物っぽい。 → **白い 1 本だけ** (`face: "hard"`)。 不規則さは**青白い火花**で出す。

## 道具の罠 (王・審判官の分に加えて)

- **設定名に `angle` `x` `y` `flip` `light` `seed` `palette` `actor` を使わない** (`core/fx.js` の createFx が、 効果全体の置き方として使う名前)。
  `angle: 60` と書いたら、 効果全体が 60 ラジアン回され、 原点からの座標で描く物 (粒・`glow`・`sparkle`・`line`) だけが画面の外へ飛んだ。 `put` / `add` (画面の左上からの座標) は無事なので、 気づきにくい。
- 計算は、 書き出しのコマ数に関係なく 1/120 秒刻み (`createFx.update`)。 1 秒 8 コマで書き出しても、 粒の寿命や動きは変わらない。
- 黒を「色」として置く効果は、 色の組の一番暗い色がそのまま出る。 鋼の組は一番暗い色を黒にしてある。
