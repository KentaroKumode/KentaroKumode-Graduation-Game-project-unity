# ヴェスカの大技の一連の流れ (試作・2026-11-14)

ヴェスカ (`boss_layer7`〜`boss_layer7_p4`)。 作者の指定は「チャージだけ守れば、 あとは自由裁量」「大技は 2 つ: 1〜3 段目の 1 つと、 4 段目だけの 1 つ」。
題材は〈停滞する時間〉と、 終層の名前 (Null Point / Signal lost)。 **1〜3 段目 = 時が止まる・4 段目 = 時が壊れる**。
どれも画面全体 (480×270)・1 秒 8 コマ・紫の色の組 (`lab/lcd_frames.mjs --ink null`) で見て作った。 作者の確認はまだ。

## 共通 (4 段とも)

| 順 | いつ | 効果 | 大きさ | 尺 |
|---|---|---|---|---|
| 1 | ヴェスカのチャージのターン | `dicebound/vesca-charge` | 画面全体 (480×270) | 2.75 秒 |
| 2 | プレイヤーの手番の間 | `dicebound/vesca-charged` (ループ) | 玉のまわりだけ (240×176) | 3 秒で 1 周 (24 コマ) |

- 原点は玉の中心 (240,130) = 敵の足もとの 66 上。
- 完了で、 **虚の玉 (`shadow/void-orb`) の上に時計の文字盤**が開く。 待機は、 渦が巻き、 粒が吸い込まれ続け、 長針が逆回り・短針が順回りで滑らかに回る (1 周に 1 回転ずつ)。
- 大技へは **0 / 6 / 12 / 18 コマ目**で入る。 溜め (`vesca-stop` / `vesca-lost`) を `phase: 0 / 0.75 / 1.5 / 2.25` の 4 本ずつ焼く (最大 0.6 秒待つ)。 溜めも玉のまわりだけ (240×176) なので、 本数が増えても軽い。

### 文字盤の作り (2026-11-14 作者の指摘で直した)

最初の版は「cheap」: 線が全部 1 ドット・針が中心からずれている・針がカチカチ進む・まわりの粒が止まっている。 直した規則:

- **線の太さを揃えない**: 輪は 2 ドット・3 時間ごとの目盛りは太く長い (3 ドット)・ほかの目盛りは細い・針は根もとが太く先が細い (長針 3.2 → 1.2・短針 4 → 2.2)・短い尾・中心の留め。
- **針は中心から対称に塗る** (`bar()`: 中心線からの距離で塗る。 `line` で引くと 1 ドット片側へ寄る)。
- **針は滑らかに回す** (1 コマ 15 度)。 1 目盛りずつ跳ばさない。
- **粒を止めない**。 止まった粒は安っぽい。 虚の玉の渦・吸い込まれる粒と筋・曲がる光を、 そのまま下に敷く (`orb()`: `shadow/void-orb` の `drawBack` / `draw` を、 位置だけずらして呼ぶ)。

## 1〜3 段目の大技: 時が止まり、 凍った画面が砕ける

| 順 | いつ | 効果 | 設定 | 尺 |
|---|---|---|---|---|
| 3 | 大技のターンの頭 | `dicebound/vesca-stop` | `phase` (4 本)・`slow: 0.8`・`lead: 1.0` | 1.0 秒 (8 コマ) |
| 4 | 3 の 8 コマ後 | `dicebound/vesca-shatter` | 既定 (`start: 1.15`・`color: "#0c0818"`) | 約 1.65 秒 (絵が無くなるまで) |

針も渦も滑らかに遅くなって止まり (0.8 秒)、 文字盤が白く抜ける → 次のコマで画面全体が凍る (色が抜ける) → 0.17 秒でひびが走る → 0.47 秒で砕けて、 破片が落ちていく。 揺れは、 砕けるコマから。

**砕けるのは「黒い硝子」ではなく、 止まった瞬間の画面そのもの** (2026-11-14 作者の指定: 黒い画面が出るのは微妙 ── 割れる寸前の画面にひびが入る形に)。

- 効果 (`vesca-shatter`・既定 `glass: "clear"`) が描くのは、 **ひび・破片の縁と照り・火花と破片の屑・閃光だけ**。 面は塗らない。
- 面は**ゲーム側**が描く: 時計が止まったコマの画面を写し取り (色を抜いて紫がかった灰色に)、 割れるまではそれを 1 枚で出し、 割れたら**破片の形に切って動かす**。 後ろには、 動いているふつうの画面。
- 破片の形は `lab/shard_dump.mjs` が JSON に出す (`{ fps, frames: [ null | [{ src, dst }] ] }`・奥から順・割れる前は null)。 `src` = 元の位置の多角形・`dst` = 今の位置の多角形。 破片ごとに `src → dst` は 1 つのアフィン変換 (写しを貼るには、 `src` を UV にして `dst` へ描く)。
  効果の中の出どころは `geom()`。 計算は効果と同じ 1/120 秒刻みなので、 縁の線と面がずれない。
- 見本の処理: `lab/vesca_flow_preview.py` の `frozen_tint()` と `shattered()`。
- 割れる中心は玉の中心 (240,130) (元は画面の中ほどの乱数)。
- `glass: "dark"` にすると、 面を黒い硝子で塗る最初の版 (この効果だけで完結する。 ゲーム側の処理が要らない代わりに、 黒い画面が出る)。

## 4 段目だけの大技: 時が壊れ、 画面が乱れて、 信号が切れる

| 順 | いつ | 効果 | 設定 | 尺 |
|---|---|---|---|---|
| 3 | 大技のターンの頭 | `dicebound/vesca-lost` | `phase` (4 本)・`lead: 1.0` | 1.0 秒 (8 コマ) |
| 4 | 3 の 8 コマ後 | `dicebound/vesca-glitch` | 既定。 **最初の 7 コマ (0.9 秒) だけ使う** | 0.9 秒 |
| 5 | 4 の 7 コマ後 | `dicebound/vesca-off` | 既定 (`start: 0.34`) | 約 1.1 秒 |

針も渦も加速し (1 秒で 7 倍)、 文字盤が横にずれて影が二重三重に出る → 黒い帯が引っかかりながら画面を覆っていく → 真っ黒 → 白い線 1 本 → 点 → 残光 → 点 → 線 → 絵が開いて戻る。

**4 段目は、 画面そのものが乱れる ── こちら側 (プレイヤーの盤・体力の帯) にも及ぶ** (2026-11-14 作者の指定: 「もうちょっとこっち側にすら干渉してる感じ」)。

- 効果を上に重ねるだけでは、 乱れるのは「敵の側の絵」に見える。 **出来上がった画面全体 (敵・盤・表示・重ねた効果) を、 横の帯ごとにずらす**処理を、 ゲーム側で最後に掛ける。
- 帯の種類は 3 つ: `shift` = 帯を横へずらす (はみ出た分は反対側から出る)・`smear` = 帯のある 1 列を横へ引き伸ばす・`ghost` = ずらした帯を、 元の上に明るい方だけ重ねる (二重像)。
- 強さ (0〜1) の運び (大技のターンの頭からのコマごと): 溜めの 8 コマで 0.1 → 0.75・乱れの 7 コマは 1.0・黒い間 0・**絵が戻った後も 9 コマかけて 0.7 → 0** (戻ってもしばらく乱れが残る)。
- コマごとの帯の表は `lab/vesca_flow_preview.py` の `tear_bands()` が作って `Captures/fxlib/_vesca/tear.json` に出す (`{ fps, w, h, frames: [[{ y, h, dx, kind }]] }`)。 見本の処理は `torn()`。 ゲームは同じ表を読むか、 同じ規則で作る。
- 1〜3 段目には掛けない (あちらは「止まる」)。

## 効果の外でゲーム側がやること

- **暗く落とす**: チャージの最初の 6 コマで 55% 暗く。 待機と溜めの間そのまま。 画面全体の効果 (4) が始まるコマで外す (その効果が画面を覆うので、 切り替えは見えない)。
- **揺れ** (1〜3 段目だけ): 砕けるコマ (4 の 3 コマ目) から `(0,4) (-3,-2) (3,2) (-2,-1) (1,1) (0,-1)` ドット。 4 段目は揺らさない (画面が切れること自体が衝撃)。
- 通しの見本: `lab/vesca_flow_preview.py` → `Captures/fxlib/_vesca/flow.html`。

## 部品と、 借りた元

| 効果 | 作り |
|---|---|
| charge | 吸い込み = `explosions/implosion` (ほかの 3 体と同じ)。 玉・渦・粒 = `shadow/void-orb` をそのまま呼ぶ。 文字盤 = `arcane/time-stop` の時計を描き直した |
| stop | 時刻そのものを遅くして待機の絵を描く = `arcane/time-stop` の「時の流れが 0 へ落ちる」 |
| lost | 時刻を加速して待機の絵を描く + 文字盤をずらして 3 重に描く (自前) |
| shatter | `transitions/shatter-wipe` を **そのまま写した** (`_screen.js` で画面を 480×270 に)。 色と硝子の色と、 始める位置 (`start`) だけ変えた |
| glitch | `transitions/glitch-wipe` を そのまま写した。 色だけ変えた。 前半だけ使う |
| off | `transitions/crt-off` を そのまま写した。 色と、 始める位置 (`start`) だけ変えた |

`dicebound/_screen.js` = `transitions/_lib.js` の画面の大きさだけを 480×270 に変えた写し。 **場面転換 (transitions) の効果は、 import をこれに替えるだけで、 このゲームの画面いっぱいに流せる** (元は 320×180 固定)。
場面転換は「覆って、 外れる」作りなので、 途中から始める (`start`)・途中で止める、 で大技の画面全体の部分に使える。
