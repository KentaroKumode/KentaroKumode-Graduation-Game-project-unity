# 業火の着弾 `dicebound/gouka-impact` (2.75 秒・1 回・440×300) — 試作

灰燼の王の大技〈業火〉が当たる瞬間。 敵を正面から見る構図。 王の足もとで白く爆ぜ、 体の左右に炎の壁が立ち、 火が床を輪になって手前まで走り、 縁で燃え残って燻る。
オプション `ash` (烈炎の数) が多いほど、 灰が噴き、 灰色の煙が残り、 床の火が長く燻る。 原点は敵の足もとの中心。
**自前で形を描き起こしたのは、 灰の塊だけ**。 ほかは全部、 炎の分類の部品を借りて、 パラメータを変えた物。

拍 (1 秒 8 コマで見た時): 0 コマ目 = まだ何も無い → 1 コマ目 = 白い閃光 + 炎の壁 + 輪 (決めのコマ) → 2〜4 コマ目 = 火球が上がり、 床の火が外へ走る →
5〜8 コマ目 = 壁が赤く縮み、 床の火は縁だけ残る・煙が立つ → 9 コマ目〜 = 煙と燻る床。

## 直した記録 (書き出して、 見て、 一番悪い所を直す)

1. 初版: 床の全面が同時に炎で埋まり、 絨毯に見えた。 王の足もとの爆発が小さい。 焦げ跡の点がノイズ。
2. 中心の炎をまばらに・短命に。 手前の炎を大きく。 火球と柱を大きく。 焦げ跡の点を減らす → 輪として走るようになった。 火球が横一列の玉に見える。
3. 炎の壁 (大きな舌 10 本) を足す → 決めのコマに形が出来た。 ただし舌が細く、 先がくねって、 線に見えた。
4. 舌の半幅を高さの 1/7 に・ゆらぎを小さく → 炎の壁として読める。

## まだ弱い所

- 火球が、 丸い玉の列に見えるコマがある (特に暖色の組)。
- 暖色の色の組では、 煙が橙の玉になる (液晶の 5 色に灰色が無い)。 **灰の色の組** (`lab/lcd_frames.mjs` の `ash`: `#2e2622 #6e5a4e #c8612a #f0a850 #fff4dc`) なら、 煙が灰色に出る。 採否は未定。
- 奥の半分の炎は、 敵の体の後ろに回せない (ゲームは効果を 1 枚で上に重ねる)。 体の幅だけ抜いてある。
- チャージ (火が小さくなる) と霧散 (取り消された時) は、 まだ書いていない。
