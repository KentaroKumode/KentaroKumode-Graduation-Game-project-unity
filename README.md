# DICE BOUND

ダイスで戦うローグライク。卒業制作として開発中のゲームです。

地の底へ続く「大穴」を、層ごとに潜っていきます。各層のマップを歩いて戦闘・ショップ・休憩・イベントをこなし、層の主を倒して次へ進みます。
戦闘は振ったダイスを攻撃・防御・充電の端子へ配線して組み立てる形で、ダイスの面に付けたパーツで役が生まれ、拾ったアイテムがキーワードを通して噛み合っていきます。

## 開発の状況

- 遊べる状態: 仮置きの GUI で 1 ラン最後まで遊べる
- 開発中: GUI の作り込み、バランスの調整、演出

## 技術

| 項目 | 内容 |
|---|---|
| エンジン | Unity 2022.3.22f1（Built-in Render Pipeline） |
| 言語 | C# |
| 画面 | 480×270 ドットの液晶を、走査線・湾曲・色収差・ブルームの自前シェーダーで描く |
| バランス調整 | 自動でゲームを遊ぶ BOT を同じシードで並べて走らせ、 変更の前後をペアで比べる |

## リポジトリについて

このリポジトリには、ソースコード・ゲームのデータ・設計資料が入っています。
絵・音・フォントの本体は含めていないので、このままでは Unity でゲームとして動きません。

| 場所 | 中身 |
|---|---|
| `Assets/Scripts/` | ゲーム本体のコード（戦闘・マップ・アイテム・メタ進行・UI） |
| `Assets/Scripts/AutoTest/` | 自動で遊ぶ BOT と、バランス計測の仕組み |
| `Assets/Data/` | アイテムなどのデータ |
| `Tools/` | 開発用の道具（計測の集計・フォントの書き出し など） |
| `docs/` | 設計資料。入口は [docs/GAME.md](docs/GAME.md) |
