**この依頼は測定だけです。** 数値・規則・BOT のコードは変えないでください（不具合を見つけたら止めて報告）。

## 目的

⑮ では、読む腕が大技の手前で混乱を満たしてしまった時（`a6`）、満たさない手は全部「攻撃 0 本」だった可能性が高いです（我慢の損 ≒ 8,659 は、攻撃 0 本の手に掛かる −10,000 の罰が混ざった値と読める）。BOT は、死ぬ時以外は攻撃 0 本の手を選べません。

そこで、**混乱を大技のターンまで温存するためなら攻撃 0 本で待ってよい**、というスイッチを入れました。これを ON にした腕を、⑮ の `S_Now`（OFF）と同じシードで比べます。

目盛りの時（⑬-1）は、待つと負けました。あの時は「1 ターン分の与ダメを捨てて、1 ターン分の与ダメを得る」が相殺されたためです。混乱ゲージでは、得が「×2.0 のターン＋大技 1 発を止める＋敵の行動が 1 回飛ぶ」になるので、結果が変わるかを見ます。

## 入ったもの（2026-11-26）

- BOT のスイッチ **`downGaugeNoAttackHold`**（既定 `False`・測定の口に登録済み）。
  - `True` の時: 規則を知る腕（`downTimingAware=True`）が、大技の 1〜2 ターン前で、かつ混乱の満タンまでの残りが 1 ターンに入れられる量以内なら、攻撃 0 本の手の −10,000 の罰を外す。
  - 規則を知らない腕・近視眼の腕には効かない。
- 実効状態の行に `downGaugeNoAttackHold=` と `downGaugeReadyShare=` が出る。
