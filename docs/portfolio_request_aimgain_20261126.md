# 依頼: ダウンの段取りを「積極的に待つ」と勝てるのか（案 C・2026-11-26）

`docs/portfolio_metrics_20261126.md` の ⑦・⑧ の続きです。結果は同じファイルに **「⑨」** として追記してください（①〜⑧ は書き換えない）。

## 目的

作者の方針: **ボスのダウン（目盛り）を、先を読む人が確実に得をする強力なアドバンテージにしたい。**
そのために、まず「今のゲームの規則のままで、BOT がもっと積極的に待てば勝率が上がるのか」を確かめる。

- 上がる → 戦闘に読みの深さはすでにある。⑦ で差が出なかったのは BOT の割引（`downAimGainShare` = 0.2）が強すぎて待たなかったから。
- 上がらない（または下がる）→ 今の規則では、狙って合わせる見返りが小さい。規則の側を直す必要がある（⑧ の案 A・B。規則の変更は作者が決める。この依頼では実装しない）。

**この依頼で変えるのは BOT の口だけ。** ゲームの数値・規則（凍結版）には一切触れない。

## 判定の書き方（守ること）

- どれかの `Aim_*` が `Aim0` に有意に勝つ → 「今の規則でも、積極的に待てば勝てる（戦闘に読みの深さはある）。BOT の割引が強すぎた」。一番良い値と、その時の待つ割合を書く。
- どの値でも勝てない → 「今の規則では、待って合わせる見返りが、待つ損を上回らない」。⑨-3 の待った戦闘だけの差を必ず添える（待った戦闘でも負けているのか、効いているが回数が少なすぎるのかで、直す場所が変わる）。
- 推測で原因を断定しない。数字が支える事と、推測を分けて書く。
- 規則（`BossDown`・`DownCancelRule`・敵の数値）の変更案は書いてよいが、実装・計測はしない。
