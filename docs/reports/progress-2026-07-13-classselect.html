戦闘リデザイン — ルールの設計（ADR-0009）

設計

「プレイスキルの介入余地を増やす」議論の結論。何を選ばせ、何が起こるかのルール面はすべて本章 ── 描画・盤面配置などの見た目の話は §3 に分離した。Status は Proposed（AutoRunner シミュレート通過で Accepted）。

棄却の経緯 — 勝負判定案がダメだった理由

勝負判定の上に配線を載せる案は構造欠陥の連鎖で棄却し、相互攻撃モデルを採択した。

柱一言で
1. ダイス配線ロール後、出目を端子（攻撃/ブロック/充電/特殊）へ割り当て。配線は次ターンも残る・未配置は攻撃へ自動合流（テンポ規約）。特殊端子はショップ商品 11 種（[接続制限 N]=同時接続ダイス数の上限、2026-07-14 確定。職業固有端子は廃止）
2. 相互攻撃モデル毎ターン両者が攻撃。自攻撃=武器素火力+攻撃端子出目 / 敵攻撃=敵基礎値+敵ダイスロール−ブロック出目。ロール勝負は完全廃止（2026-07-14）── トリガー層は「収支」（与ダメ−被ダメ）に置換、OnRollWin/Lose を収支±に再定義。勝敗表示は収支表示へ
3. 完全情報テレグラフ敵攻撃値・スケール段階を全公開。「被弾を効率よく受ける」レース判断が熟練の中身
4. 段階エスカレーション敵攻撃値が T5/10/15/20 でスケール。ラッシュ=HP 前払い / グラインド=スケール後払い。敵別プロファイル
5. パッシブ電力経済パッシブ=電源を要する装置。充電端子（ダイス個数参照・最大10）から毎ターン維持費を消費、不足で全停止

レイヤリング原則（2026-07-14 確定）

ダイス=物理のみ（個数/面数・ロジックなし） / 端子=変換 / パッシブ=常時装置（要電力）の 3 層に固定。 ダイス側パッシブは廃止し、既存 7 種（完全/星導/運命/星命/永劫/貪欲/諸刃）はパッシブアイテムへ転生。 あわせて「見えない補正の禁止」: パッシブは LED の出目を書き換えない（例外は表示が実際に変わる「出目操作」カテゴリのみ） ── 「LED に見えている出目 = 配線に使える値」を常に真にし、収支プレビューの信頼性を保証する。

敵が先に振って実値を予告し、プレイヤーが応手する（分布への賭けではなく実値への応手）。 充電消費が予告より前なのは、停電の有無が確定しないと配線の収支計算が立たないため。 解決はプレイヤー先制・撃破時は敵攻撃なし。旧ルール「振り直し後の配線変更不可」は廃止。

柱5（電力経済）の確定仕様 Q&A — 6 論点
論点決定
不足時の挙動全停止。呪い・デメリット系も止まる（停電悪用はニッチとして許容）
課税範囲全パッシブ系統。ただしデバフは消費数 N に数えない
停止範囲戦闘中トリガーのみ。OnMapMove / CombatEnd 系は免税
消費量の確定ターン開始時の通電対象所持数。毎ターン再計算 = 寂照/迷妄の枚数変動にも自動追従
消費予測の表示計器盤の充電ゲージで消費予定分の目盛りが点滅
残る宿題数値のみ（N / 最大ゲージ / 初期充電 / スケール傾斜）→ AutoRunner スイープで決定

正本: docs/adr/0009-mutual-attack-combat.md（棄却理由も制約として記録）。 影響: DAMAGE_CALC_REFERENCE 全面改訂 / enemies.json に攻撃値+プロファイル新設 / ADR-0005/0006 は Accepted 時に superseded。

描画規約と盤面レイアウト（ADR-0008 / W1）

計画

§2 のルールをどこに・どう描くかの章。描画ゾーン規約（ADR-0008）とその適用としての机上配置図をまとめる。

描画ゾーン規約（ADR-0008・確定）

  • LCD 内 = 平行投影・dot 厳守（読む情報: 敵インテント / ダメージプレビュー / フェーズ画面）
  • ワールド = 透視 + 2D スプライトの 3D 空間配置＝疑似3D を許可（触る装置: ダイス / 端子 / 配線）。UI 改修がスプライト差し替えで済む構造にする
  • 判定基準: 数値・テキストは LCD、機械の部品として実在してほしいクリック対象はワールド。跨る表現は入力=ワールド / 出力=LCD に分割
  • 棚卸しでの発見: HP/空腹/希望/ターンの本番 UI は未実装（IMGUI デバッグのみ）→ 盤上「計器盤」を新設。GOLD は物理コイン（CoinSystem）で表示済み = 新造不要

机上配置図（提案版・座標実測待ち）

緑実線=既存、橙破線=新規、青破線=カメラと動線。

視線動線は ① LCD（インテント確認）→ ② ダイス卓（出目）→ ③ 配線盤（采配・介入時のみ）→ ④ LCD（プレビュー・確定） の Z 字。計器盤は ①↔② の中間に置く。

実測メモ: エディットモードで確認済みの構図は「上からほぼ真下を見下ろす卓上ガジェット」（LCD Quad はほぼ水平・俯角 72°・FOV 29）。 ダイス/モニター/グリッドは実行時生成のため、正確な座標は Play 中の再計測待ち。
