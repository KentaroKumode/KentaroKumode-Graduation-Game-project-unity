1相互攻撃モデル導入の直接副作用 起点

ADR-0009 の相互攻撃パイプライン (ExecuteTurnMutual) 導入で、旧「ロール勝負」前提の設計要素が 3 系統で壊れた。以降の調整は全てこの副作用への応答。

3 つの副作用

  • 敵パッシブの発火経路が崩れる — 1759行の OnPreDealDamage は playerWonRoll==true 時 (自攻撃の残り値) を触るため、6F JudgmentBlaze の ×coef+coef が敵攻撃に反映されない
  • 「ロール勝敗」概念が消失 — OnRollWin/Lose は解決後の収支トリガーに再定義。ラベルも「収支勝率」に変更
  • 配線判断が常時発生 — 攻撃/ブロック/充電の 3 端子分配が毎T必要になり、序盤 T1=1dice では判断成立せず

26F 灰燼の王リワーク v2 完了

相互攻撃で全パッシブが壊れた 6F を段階的にリワーク。v1 で発火経路を修正し、v2 で HP50% 閾値の二相型に転換。

3キーワードビルド軸拡張 5軸+42品

配線判断が意味を持つには十分な選択肢が必要。 相互攻撃モデルに沿った新軸を 5 系統追加。 Burn は Bleed との機構重複で全廃、後継として「臨界」を新設。

軸コンセプトパッシブアイテム代表パッシブ
充電 (Charge)リソース経済・過充電で継続火力99Battery / Spark / Overload / 短絡
臨界 (Rinkai)メーター蓄積 → 閾値で爆発99Ignition / CriticalPressure / UnyieldingHeat
毒 (Poison)拘束/妨害・敵攻撃-N が主効果99Paralysis / AssassinToxin / SlowVenomCurse
鈍器 (Bludgeon)会心捨て・非会心強化のトレードオフ99HeavyStrike / BluntWeapon / SingleMinded
出血 拡張 (Bleed ext)既存 Bleed に消費/爆発を追加66BloodStrike / AntiClotting / Wringing

「臨界」メーター機構 (詳細)

  • 毎T 攻撃配線ダイス合計 (attackSum) を rinkaiMeter に加算
  • 閾値 (基準 50、LowerThreshold で 35) 到達で次T の攻撃に +50 flat 予約
  • 予約消費後 meter は 0 or rinkaiAfterglow (Afterglow: 20 / NoCooldown: threshold/2) に
  • ChainCombustion で爆発T の攻撃は会心確定 / UnyieldingHeat は meter≥40 で致命耐え (Immortalflame 継承)
