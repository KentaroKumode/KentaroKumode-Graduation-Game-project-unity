# 観点の一覧（どう壊しに行くか）

機能の一覧（[feature-inventory.md](feature-inventory.md)）の各単位に、ここの観点を掛けて項目を作ります。
「当てはまる機能」は機能の一覧の大分類の記号（A〜M）です。
「担当」は `自動` = ロジックの自動実行（Unity なしの検算台・AutoRunner・エディタのテスト）／`人` = 人が画面で／`両` = 両方。

番号は `V-連番`。前半（V-01〜V-15）は一般の観点、後半（V-16〜）はこのゲームに固有の観点です。
固有の観点の根拠は GAME.md の節・memory・コードの file:line で示します。読んで見つけた罠には「（コードを読んで追加）」と書きます。
