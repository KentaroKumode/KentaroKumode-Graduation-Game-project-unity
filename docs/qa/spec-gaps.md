# 仕様の穴の一覧（初版）

[test-plan.md](test-plan.md) から索引しています。項目書の期待値は「コードを見ずに仕様から書く」のが原則なので、
ここに載った所は**期待値が書けない／書くと間違う所**です。1 件ずつ、作者が「直す（コード）」「仕様に書く」「受け入れる」のどれかを決めます。

## 欄の意味

- **種類**: `食` = 仕様とコード（またはデータ）が食い違う／`無` = 仕様に書いていない挙動／`未` = 決まっていない（§23 など）／`矛` = 文書の中で食い違う／`疑` = 不具合の疑い（コードを読んだ見立て・実機では未確認）。
- **重さ**（項目書を書く上での影響の見立て）: `重` = 進行・記録・決定性に関わる、または誤った期待値で多数の項目が狂う／`中` = 1 機能の期待値が狂う／`軽` = 文書の古い記述。
- **場所**: GAME.md の節と行（`GAME.md:行`）・コードの file:line（`Assets/Scripts/` は省略）。
- **事実/見立て**: 数えた・読んだことは事実、そこからの推定は「見立て」と書く。実機で確かめたものは無い（全件 未確認）。
