2026-11-14〜。エディタの Play モード中に、MCP の `execute_code` から 1 行ずつ呼ぶ（キーは押せなくてよい）。正本は `Assets/Scripts/UI/Game2D/Battle/QaBattle.cs`（エディタと開発ビルドだけ）。

0. **マウスで動かす窓**（2026-11-14・作者向け）: メニュー `Tools/DICE BOUND/演出テスト`。Play の間だけ押せる（Play でない時は「Play に入ってください」）。上にセーブ抑止が立っているかが常に出る（立っていない時は赤・「開始」を押すと立つ）。できる事: 敵（ボス → ふつうの敵の順・`EnemyDatabase` の全部）・武器の家系・HP を選んで「開始」/「敵・武器を替えて始め直す」（下の 1・2 と同じ）・「1 ターン進める」「会心で進める」「次のターンをチャージに」「ヴェスカの次の遺物」（4・5・6）・ボスの大技の「チャージ」「大技」「取り消し」・武器の攻撃（家系と会心）・`Resources/Game2DFx` の絵を 1 枚選んで「再生」（検索と種類の絞り込みつき・絵を置くだけで一覧に出る・`move-*` は技の経路、`weapon-*` は武器の経路、それ以外は画面の左上か基準点に 1 回・ループの絵は 4 秒）・速さ（1 / 0.5 / 0.25 倍・一時停止・1 コマ送り。戦闘の演出の時計だけで、`Time.timeScale` は触らない。窓を閉じる・Play を抜けると 1 倍に戻る）・下に `Status()`・GUI に掛かっている値・`MoveLog()` を 0.2 秒おきに出す。
1. **戦闘に入る**: `UI.Game2D.Battle.QaBattle.Start("boss_layer6", "axe")`。敵は `boss_layer6`（灰燼の王）・`boss_layer5`（審判官）・`boss_layer5_hidden`（シュヴァリエ）・`boss_layer7` / `_p2` / `_p3` / `_p4`（ヴェスカ）・ふつうの敵の id。武器は `sword` / `axe` / `dagger` / `shield` / `"none"`（素手）。3 つ目の引数は HP（最大と今・既定 9999）。タイトルからならランを始め、ロード画面は出さずにすぐ戦闘の画面になる。
2. **敵・武器を替える**: `QaBattle.Restart("boss_layer7_p4", "dagger")`。ランを作り直さず、戦闘中なら決着の処理（報酬・段の移り）を通さずに打ち切って始め直す（`Start` もランがあれば同じ動き）。
3. **セーブは書かれない**: `Start` / `Restart` が `GameLoop.SaveGuard.Suppressed` を立てる。中断セーブ・メタ進行・設定・手引きの印・観測所を書かない（読むのは普段どおり）。Play モードを抜けるまで立ったまま。手引きは全部「見た」にして出さない。
4. **1 ターン進める**: `QaBattle.Go()`（おまかせで挿して決定）・`QaBattle.GoCrit()`（そのターンの攻撃を会心に）。1 回呼べば、判断待ちになるのを待ってから、決まるまで押し切る（振り直しの判断で止まっても押し直す）。勝ち / 負けの画面なら「次へ」を 1 回。進んだかは `QaBattle.Status()` の `go=`（`pending` = 待ち中 / `done (N 回押した)` = 進んだ / `timeout` = 20 秒待っても進まない）。続けて呼ぶのは `go=done` を見てから。
5. **大技を呼ぶ**: 判断待ちの間に `QaBattle.ChargeNextTurn()`。戻り値 1 なら、次のターン（T+1）の敵の行動がチャージ、T+2 の敵の行動が大技 ── つまり `Go()` の 1 回目で T が終わり、2 回目の終わりにチャージ → 待機、3 回目の終わりに大技。今のターンは変えない（攻撃値と予告はターンの頭に決まっているため）。2 以上が返ったら「その数 − 1 回 `Go()` してから呼び直す」（灰燼の王の戦闘の最初の数ターン・周期 2 の敵）。−1 は大技を持たない敵。ダウンは作れないので、取り消しは `QaBattle.DemoCancel()` で見る。
6. **ボスの通常の技を確かめる**: 流れで流した絵は `QaBattle.MoveLog()`（「T3 move-relic-guard」の形・`MoveLog(3)` でそのターンだけ）に残る（大技は `charge:` / `heavy:`・武器は `weapon-…`）。ヴェスカは判断待ちの間に `QaBattle.ForceRelic("guard")`（`strike` / `guard` / `hex` か 攻撃 / 防御 / 妨害）→ `Go()` で、次のターンの頭に その種類の遺物を使う。契機: 遺物 = ヴェスカのターンの頭・〈灰の再生〉= 王の HP が 50% より上で回復したターンの頭（最初のターンは満タンなので出ない）・〈審判の炎〉= 審判官の攻撃の後（毎ターン）・突き = 王とシュヴァリエの通常攻撃が当たった瞬間・構え = シュヴァリエの形態が変わったターンの頭（盾を割るか 3 回負けた後で、めったに無い → `DemoMove("move-chev-stance")` で見る）。**画面の下・左右は GUI の板に隠れる**: 絵は 480×270 の全面に描いてあり、遺物・攻撃（`relic-strike` 見える所 42%）・王の通常攻撃（29%）・審判の炎（33%）・シュヴァリエの突き（19%）・天与の剣 / 指輪は下の盤のあたりが主で、ほとんど GUI の下になる。防御・妨害・灰の再生・構え・天与の盾は 9 割以上見える。
7. **演出だけを直接流す**（キー K / J / H / Space と同じ・戦闘の流れを通さない）: `DemoBoss("Judge")` → `DemoCharge()` → 待機が出たら `DemoHeavy()`。`DemoMove("move-king-regen")`・`DemoAttack("dagger", true)`。種類は `King` / `Judge` / `Chevalier` / `Vesca` / `VescaFinal`。
