# パッシブアイテム命名・フレーバー規約

更新日: 2026-08-12

## 目的

パッシブアイテムを「効果に名前を付けたもの」ではなく、ヴェイランドへ流れ着いた実在の品として扱う。効果値、レアリティ、内部 ID、入手経路は変更しない。

参考にしたのは、アークナイツ統合戦略「探索者と銀氷の果て」の秘宝一覧に見られる次の構成である。

- 名前は短く、まず物の姿を示す。
- 効果説明とフレーバーを分離する。
- フレーバーは用途、以前の持ち主、土地の習慣、記録の欠落から世界を見せる。
- 日用品、軍用品、文書、奇物を同じ世界の流通品として並べる。

参照: https://arknights.wikiru.jp/index.php?%E7%B5%B1%E5%90%88%E6%88%A6%E7%95%A5%E3%80%8C%E6%8E%A2%E7%B4%A2%E8%80%85%E3%81%A8%E9%8A%80%E6%B0%B7%E3%81%AE%E6%9E%9C%E3%81%A6%E3%80%8D/%E7%A7%98%E5%AE%9D%E4%B8%80%E8%A6%A7

## 命名規則

1. 原則として、装備、道具、文書、容器、標本、部品などの具体物をアイテム名にする。
2. アイテム名とパッシブ名を分離する。前者は具体物、後者は作用・技法・状態を示す。
3. 技名・状態名だけのアイテム名は避ける。必要な場合は「〜の指輪」「〜の手控え」のように媒体を示す。
4. 現実世界の神話名・外国語名を直接借りず、本作の土地・組織・用途へ置き換える。
5. 同系統の段階品は、同じ土地・組織・事件に由来する小さな連作にする。
6. BRONZE は市井の実用品、SILVER は改造品や職能品、GOLD は由来のある品、LEGENDARY は記録や因果が壊れた品を基本とする。
7. 固有名はヴェイランド、旧アルフォニア、ストレリツ、ホーリン、寂照、大穴の既存ロアから取る。
8. 表示名だけを変更し、セーブ互換性を担う `id` と効果実装用 `internalName` は変更しない。

## フレーバー規則

- 効果を数値で言い直さない。挙動は連想できる程度に留める。
- 「伝説の」「神秘的な」「古代の」だけで価値を説明しない。
- 誰が、どこで、何に使ったかのうち一つ以上を置く。
- 鑑定記録、但し書き、商人の口上、持ち主の逸話など、世界内の観測者を置く。
- BRONZE は一〜二文、SILVER/GOLD は二〜三文、LEGENDARY は必要な場合のみ長くする。
- 説明し切らず、最後に小さな欠落、反転、嫌な余韻のいずれかを残す。

## 命名の構文（2026-09-15 追記）

規則 1〜8 に加えて、**名前の作りそのもの**についての取り決め。
2026-09-15 に新規 8 品を `[修飾]の[物]` だけで作ってしまい、全品を付け直したときの決定。

### 名前で効果を説明しない

**名前を読んだ時点で効果が分かる名前は付けない。** 名前と効果のあいだに一段の飛躍を置き、
その橋渡しはフレーバーにやらせる。

| | |
|---|---|
| 悪い | 〈釣り銭の受け皿〉＝ 買うたび希望+1 / 〈精鋭首の請取証〉＝ エリート勝利でゴールド+2 |
| 良い | 〈銭皿〉〈首級控え〉── 物の名前だけ。なぜそうなるかはフレーバーが引き受ける |

参照したのは Limbus Company の E.G.O ギフト（「盛大な歓待」＝資源獲得、
「コーヒーと折り鶴」＝ランダム資源）。**ただし規則 1「具体物を名前にする」は維持する** ──
「赤色の指令」「塵は塵に」のような出来事・概念の名前は採らない。

### 構文型を偏らせない

2026-09-15 時点で **`[修飾]の[物]` が 115 品中 85 品（74%）**。この型は既に飽和している。

- **新規で同じ構文型を 3 つ以上並べない**（同一バッチでは特に）
- 使える型: 単独の物（鉄盾 / 荒砥）/ 連体修飾節＋物（夏を語らぬ炉壁 / 擦り減った小盾）/
  状態＋物（気短な早沸かし釜）/ 複合（首級控え）/ `[修飾]の[物]`
- 字数も散らす（2〜7 字。既存は 5〜9 字に偏っている）

### 外来語

規則 4 が禁じているのは**現実の神話名・固有名の直接借用**（ヘルメスの靴 → 帝国伝令の三日靴）で、
**道具の外来語は禁じていない**。既存例は〈点火スパナ〉〈シュヴァリエのレイピア〉（日用品の register）と
〈ノクタリア〉〈ドーンブリンガー〉（LEGENDARY の造語固有名）。

ただし **機能から逆算した造語は避ける**。〈木札トークン〉〈チップトレー〉は
「リロール」「釣り銭」という機能語をそのまま外来語に置き換えただけで、飛躍が無い。
