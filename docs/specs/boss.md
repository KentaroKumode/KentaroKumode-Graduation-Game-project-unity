# ボスと自動難易度調整

## Purpose

各フロアの到達点はボス戦。5層ボスが通常クリア、7層ボスが完全クリアの区切り。ボスの難易度は
オートランで計測した死因診断に基づき自動チューナー(L3)が調整する。正本: 戦闘は
[CombatManager.cs](../../Assets/Scripts/CombatSystem/CombatManager.cs)、調整は `AutoTest/`。

## Definition

### 層ごとのボス構造

- **5層ボス**：通常クリア地点（`RunState.IsNormalClear`）。手前の `karma_trap` でカルマ清算
  （最大HP −= カルマ×10、最低1、清算後 karma=0）。5層には裏ボス「シュヴァリエ・サン=ジョリオラ」
  があり、撃破で `defeatedSaintGeorges` 成立（レイピア解除時に会心+9 補正）。
- **6層**：`SinAltar`（祭壇マス）で3つの儀式を支払う。不払いに応じ永続デバフ `SinDebuff` を付与し
  **6層ボス戦中のみ**ボスのステータス／パッシブを変質させる。
  - ゴルゴダの心（HPの儀）／断絶した時間（金銭の儀）／灰燼の烙印（遺品の儀）。複数同時所持可。
- **7層**：最終ボス＝**覚者**（最終形態：妙覚）。`IsFullClear`。進入には〈真理〉(`convictionStage` ≥ 6) が
  必要（メカ）。lore 的には「6層の玉座を蹴って向こう側に至った狂人」だけが踏める領域
  （[lore-endings §1-D/§1-E](lore-endings.md)）。

### ボス自動チューナー L3（正本: `AutoTest/BossTuning.cs`, `BossBalanceTuner.cs`）

- 実装：`BossTuning.cs`（`BossParam` enum + `ParamMeta` + override 方式）、
  `BossBalanceTuner.cs`（`DiagnoseStruggle` が `BossParam?` を返す）、
  各パッシブは `EnemyPassiveSkillEffects.cs` で `BossTuning.Param/ParamInt` を直接読む。
- **方針（規約）**：
  - 隠し倍率（×1.xx）を**禁止**。目標勝率を出したら、各パッシブの**実数値そのもの**
    （断罪ダイス上乗せ・断罪係数 base・天衣無縫上限・反射率%・審判の炎上限・爆ぜ火固定ダメ・
    灰塵の鎧軽減量・**威圧の脅威(+3基準)**・**毒スタック上限(3層・基準5)**・**反射上限(4層・基準9)**・
    HP 絶対値・ダイス期待値→構成／固有面）を増減して落ち着かせる。
  - 死因タグ→対応レバーは**ボスが実際に持つスキル**で選ぶ（`HasSkill`）。例: Chip 死亡なら審判の炎(5層)か毒の侵蝕(3層)、
    Reflect 死亡なら鏡映の応答(4層)。
  - 候補レバーは**優先順位つき**で、本命が範囲飽和（例: 審判の炎上限が下限1）なら次点（例: 威圧の脅威）へ
    自動フォールスルーする（`AdjustParam` が変化有無を返す）。
  - **大原則**：調整は**勝率(クリア率)が目標帯(DeadZone)から外れたときだけ**行う。ロール勝率の調整は
    クリア率調整の*手段*であって目的ではない＝**勝率が問題ないのにロール勝率をレンジへ寄せにいくことはしない**。
  - **レバー優先順**（勝率が目標外のときのみ）：① スキル(各ボスの特色・死因の被ダメ支配率で本命選択) →
    ② ダイス/固有面 → ③ 弱ロール比 `WeakRollRatio` → ④ 攻撃力(高火力スタンス倍率 `StanceAtkMult` 基準1.6) → ⑤ HP。
  - **ロール勝率レンジは②③の「ゲート(制約)」**：クリア率errで動かすが、 **ボスのスタンス別 roll-win がレンジを割る方向の
    調整は不可**（巻き戻して次レバーへ）。強ロール時 roll-win→ダイス/固有面(`AdjustStrongDiceForClear`)、
    弱ロール時 roll-win→弱ロール比(`AdjustWeakRatioForClear`)を、 `BossTuning.Strong/WeakRollWinRange(id)`(per-boss設定・
    弱ロールは高火力との交換で低め)で挟む。＝「5d9張り付き／一方的ロール」を防ぐが、 レンジへの能動収束はしない。
  - ボスの「攻撃力」は新規フラット値ではなく**既存の敵スタンス高火力倍率**を per-boss 可変にして表現（隠し倍率でなく機構の実数）。
  - **死因は「キル時の一撃」ではなく「戦闘総被ダメに占める各ソースの支配率」で診断**する。
    各特殊スキルが与ダメを `CombatContext.AddPlayerDamageSource` で計上し、メイン被ダメ（ロール敗北/断罪増幅）は
    適用時に `lastDamageCause` で帰属。ボス別に全戦闘ぶんを合算し、総被ダメの ≥40% を占めるソースを本命レバーにする。
  - ある死因が被ダメ支配でも短絡しない。**多角診断**（例：断罪支配でもロール勝率が低い→断罪ダイス／勝てて稀な致命→断罪係数）。
  - **変更が無いバッチも changelog に「変更なし」を必ず追記**（調整が走った記録を残す）。
  - **7層ボス**は上記の難易度調整を行わず、唯一「真我」(素ロール固定加算)でロール勝率を目標へ寄せる（妙覚=サドンデス専用は学習停止）。

### ボス固有ダイス（署名ダイス・ADR-0007）

均一ダイスは `E25 (5d9)` が上限で、強ビルドの基礎ロール（例: 4D完全 E26〜、フラット加算で E33+）に追従できず、
チューナーが HP 水増しに陥っていた。これを解消するため、対象4ボスに**固有の面構成ダイス**を与える。

- 対象（5個振り・面6つ・各値∈[1,9]）：
  - 5層 業火の審判官「裁火のダイス」`[2,3,3,6,7,8]`（二極・E24.2）
  - 5層裏 シュヴァリエ「決闘のダイス」`[4,5,5,6,6,7]`（低分散・E27.5）
  - 6層 灰燼の王「薄火のダイス」`[4,6,7,7,8,8]`（上寄り・E33.3／+灰塵の威圧+3）
  - 7層 覚者「往生呪のダイス」`[7,8,8,9,9,9]`（高い床・E42.5）
- 実装：`EnemyData.diceFaces`（固有面）→ `CombatManager` の敵ロールが面から抽選。弱ロールスタンスは
  `EnemyStance.WeakRollFaces` で各面を一律縮小。`BossTuning.Apply` が対象ボスへ面を注入（均一 `BestDiceConfig` をバイパス）。
- **学習**：L3 が**面の各値そのもの**を実数値で増減（`AdjustSignatureDice`）。クリア率errで動かすが、
  **強ロール時のボス roll-win がレンジを割る方向は不可**（`AdjustStrongDiceForClear` のゲート）＝難しすぎ時は高い面を下げ、
  易しすぎ時は低い面を上げるが、 roll-win レンジ内に留める。既定面は `BossTuning._signatureDefaults`、学習値は
  `boss_tuning.json` の `Knob.diceFaces`。
- 5層/5裏/6層は面＋弱ロール比でロール勝率を帯内に保ちつつ難度はスキル/攻撃力/HPで。**7層覚者**は往生呪ダイスを
  **ベースロール**に使いつつ、上限超えの調整は従来どおり「真我」が担う（多段戦＋ロール勝率制御の既存設計を尊重）。

## Constraints

- MUST：L3 チューナーは隠し倍率を用いず、パッシブの具体的実数値（固有ダイスは各面の値）を直接動かす。
- MUST：死因に短絡せず多角的に原因を切り分ける。
- MUST：固有ダイスの1面の値は [1,9]（11等はグラフィック表現不可）。
- MUST NOT：7層ボスを通常難易度調整（HP/機構）の対象にしない（真我のみ）。
