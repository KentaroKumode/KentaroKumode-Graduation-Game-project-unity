# 体験の大目標（2026-11-17・作者の宣言）

このゲームのレベルデザインとバランス調整の、いちばん上の目標。GAME.md とは分けて置く（大型の目標なので、仕様の正本の検索を重くしないため・作者の指示）。
調整案は、すべて「この 2 つの体験の、どちらを・どう強めるか」で説明する。

## 宣言

> **このゲームは、2 つの体験を両方持つ。**
>
> **(1) 俺ツエーの回** — ランの途中で組み合わせが噛み合い、力が掛け算で伸びて、ボスを溶かす。狙えば作れて、ゲームが後から打ち消さない。
>
> **(2) 引きの悪さを知識で乗り切る回** — 弱い物を配られても、知っている人は判断（道・店・イベント・配線）で勝ち筋を作れる。
>
> **クリア率は、この 2 つが成り立った結果として合わせる。** クリア率を先に合わせて、体験を後から探すことはしない。

## 物差し（指標と目標）

測る条件は、断りが無ければ §13-5 の基準（Super・難易度 0）にそろえる。整備パネルの点数は指標ごとに書く。
**目標の数字は暫定**。段階 2（診断）で今の値を測った後に、作者と見直す。

| 指標 | 中身 | 目標 | 状態 |
|---|---|---|---|
| **俺ツエーの率** | 全ランのうち、力が想定を大きく超えたランの割合 | **全体の 5〜10%**（作者 2026-11-17） | 判定の定義は段階 1 で決める |
| **知識の関与** | 引きの悪いラン（引きの質が下位 1/4）で、知識のある BOT と無い BOT のクリア率の差 | **大きく効く**（作者「かなり関与すべき」）。暫定の目安: 知識のある BOT が、引きの悪いランで無い BOT の 2 倍以上勝ち、かつ自分の全体のクリア率の半分以上を保つ | 知識の段を分けた BOT と、引きの質の点数を段階 1 で作る |
| **整備パネルの伸び方** | 点数 0・12・24 でのクリア率 | 暫定（作者の委任・下の §「パネルの伸び方」） | 段階 2 で今の形を測る |
| **クリア率** | 全体のクリア | 20〜25%（Super・§13-5 のまま） | 上の 3 つを満たした後で合わせる |

### 俺ツエーの判定の決め方（段階 1）
- **絶対の基準で決める**。「上位 10% を俺ツエーと呼ぶ」のような分位で決めると、どんなゲームでも必ず 10% になる（同語反復）。
- 候補（どれか、または組み合わせ）:
  - 3 層のボスを、想定（§13-5 の「ボス 10 ターン超が好ましい」）の 1/3 以下のターンで倒した
  - 1 ターンに、ボスの最大 HP の一定割合以上を与えた
  - ランの後半の戦闘で、受けたダメージがほぼ 0 のまま勝ち続けた
- 候補ごとに今の分布を出し、作者が手触り（実際に遊んで「壊れた」と感じた回）と照らして選ぶ。

### 知識の関与の測り方（段階 1）
- **引きの質の点数**: 同じシードで、棚・報酬・イベントに出た物から、そのランの運の良さを点数にする。プレイヤーの判断に依らない値だけで作る。
- **知識の段を分けた BOT**: 今の梯子（Naive → Optimal → Super）は、「知識」（規則で分かる正解）と「計算力」（先読み）が混ざっている。知識だけを足した段を作り、計算力の差と切り分ける。
- 参考（測定の記録）: 難易度 0 で Super 20.2% / Optimal 6.7% / Naive 5.7%（2026-11-12）。知識の段（Optimal）と何も考えない段（Naive）の差が 1pt しかない。

### パネルの伸び方（作者の委任・暫定）
整備パネルの素の数値は**残す**。役目は 2 つ。
1. 勝てない人を救う安全網
2. 最高難易度と最低難易度の幅の土台

決めるのは「伸び方の形」。暫定の目標（Super・難易度 0）:

| パネルの点数 | クリア率の目安 | ねらい |
|---|---|---|
| 0 点（最初のラン） | 10% 前後 | 最初のランでも、判断で勝てる手応えが返る。今の 4.9%（Optimal・2026-11-05）は、知識が育つ時期に「運と周回のゲーム」だと教えてしまう |
| 12 点 | 15〜20% | |
| 24 点（育ちきり） | 20〜25% | §13-5 の目標そのもの |

- 知識が効いているかは、**パネルの点数を固定して**測る（周回で強くなった分と混ざるため）。
- 0 点の床の上げ方は、段階 3 で設計する（最初の数点の効き方・点の貯まる速さ）。

## 進め方

| 段階 | 中身 | 状態 |
|---|---|---|
| 0 | 宣言と物差しの定義（この文書） | 済（2026-11-17） |
| 1 | 物差しを作る（計装・引きの質の点数・知識の段の BOT・俺ツエーの判定）。ゲームの挙動は変えない | 済（2026-11-17・a4f6bf16〜f7c505ac・集計 `Tools/experience_report.py`） |
| 2 | 診断: 今の値を測る。どの判断が効いているかを測り直す（2026-08 のアブレーションは古い）。俺ツエーの回の中身を調べる | 済（2026-11-17・下の「段階 2 の結果」） |
| 3 | 作り直し（効き目の大きい順・1 つずつ・案 → 採否 → 実装 → 同じシードの対で比べる）: ダイスの作り直し / 足し算だけの秘宝を別の品として作り直す / 知識の入らない確率分岐のイベント / ボスを「崩し方がある壁」へ / パネルの伸び方 | 未着手 |
| 4 | 合わせ直し: 3 つの指標を目標に入れた後で、クリア率を合わせる。クリア率だけで合わせない | 未着手 |
| 5 | 人が遊んで確かめる（BOT に手触りは分からない）。強い構成・弱い引きから始める確認の口を用意する | 未着手 |

測定は、ラン数と秒数を先に出して承認を取ってから回す。落とした案は docs/design-rejects.md に残す。

## 段階 2 の結果（2026-11-17・164,000 ラン）

条件: 難易度 0・遺物なし・イベントあり・**嵐なし**・ITT の序列で買う・同じシード（1,000,000 + i）・学習に合流しない。各腕の方策とパネルの点数は全ランの実効状態で確かめた。
**嵐あり（製品の既定）では Super 2.1%（n=4,000）**。下の数字はすべて嵐なしの値で、嵐ありの条件では梯子もアブレーションも測っていない。

| 指標 | 今の値 | 目標との差 |
|---|---|---|
| 俺ツエーの率（候補 A: 3 層のボスを 5 ターン以内・Super） | 3.5%（候補 C: 4 層・ヴェスカも含めて 4.5%） | 目標 5〜10% に届かない |
| 知識の関与（引きの質の下位 1/4・2,000 シード） | Naive 1.6% / 規則の知識の全部（K6）2.2%（×1.23・有意でない）/ + 航行の計画（K7）9.6% / Super 15.4%（全体比 0.48） | 規則の知識では差が出ない。効いているのは航行の計画（計算）と ITT の Super 版の表だけ |
| パネルの伸び方（Super） | 0 点 0.5% / 12 点 9.1%（配り方は仮）/ 24 点 32.2% | 下に凸（後半の点ほど効く）。目安（0 点 10% 前後）と逆。0 点では梯子の全段が 0.0〜0.5% に潰れる |
| クリア率 | Super 32.2% / Optimal 11.5% / Naive 9.4% | 目標 20〜25% より高い（嵐なし） |

**判断の効き目**（Super から潰した時のクリア率の落ち幅・各 4,000 ラン・百分率ポイント）: 店 −30.6 / イベント −28.9 / 航行の行き先 −25.7 / 店の順位付けだけ −23.9 / 戦闘の配線 −12.4。2026-08 より航行と配線が厚くなった。

**俺ツエーの回の中身**（観測の比較・因果ではない）: 3 層のボスを 5 ターン以内に倒す回は「出血の軸 × 血桜」と「溶金の領主剣」に集中している。血桜も溶金も無いと 1.1%、両方あると 77.8%（n=36）。1 ターンでボスの最大 HP 以上を与えた回は 8,000 ランで 0 回。

詳細: `Captures/experience/results.md`（git の外）。
