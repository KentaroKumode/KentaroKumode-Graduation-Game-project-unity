# GUI スナップショット（2026-10-15）

来週の進捗報告で、ビフォーアフターの「ビフォー」に使う。実装済みの GUI コンポーネントを、**試作で実際に表示される位置・状態**のまま PNG にしたもの。

## ファイル

| ファイル | 中身 |
|---|---|
| `gui_before_sheet.png` | 下の 3 状態を横に並べた結合画像（実寸 1 倍・1456×270）。地の色（24,28,36）は透明部分を見やすくするだけで、GUI には含まれない |
| `gui_layer_nav_pot_closed.png` | 航行・GOLD 入れが閉じた状態。480×270・透明。コンポーネントの PNG を、実際の位置で重ねた絵そのもの（画素は試作の描画バッファと同一） |
| `gui_layer_nav_pot_open.png` | 航行・GOLD 入れが開いた状態 |
| `gui_layer_battle.png` | 戦闘中（物資のバーが引っ込んだ状態） |
| `display_*.png` | 上と同じ状態の「画面に出ている見た目」（液晶の影・格子・湾曲をかけたあと。960×540）。地図と PAUSE の文字も入る |
| `counter_native.png` / `counter_x10.png` | アナログカウンターの窓だけ（48×20 と 10 倍）。表示は `01234` |
| `state.json` | 撮った時の状態（物資 1000/1000・HP 40・GOLD 30・シード 1・液晶倍率 2・コミット d021704） |

## 含まれるもの・含まれないもの

- 含まれる: GOLD 入れ、操作パネル（TRAP / FLARE / RECON と残弾ランプ）、レーダー、物資バー（汚し版の土台・窓・バー・ランプ枠）。
- 含まれない（地図の層に描くもの）: 出口のコンパス、天候の表示、PAUSE の文字、各エフェクト。これらは `display_*.png` の側で見える。
- HP バー・数字のカウンターは、試作にはまだ組み込んでいない（カウンターは単独ページ `gui-counter.html`）。

## 撮り直し（アフター用）

同じ手順で撮れる。条件（状態・待ち時間）が同じなので、そのまま見比べられる。

```
python Tools/snap_gui.py docs/progress/gui_snapshot_<日付>
```

必要なもの: Chrome、Python の `websocket-client` と `Pillow`。Unity は不要。

## 注意

- 撮影時点の `map-prototype.html` は**未コミット**（HEAD は d021704 のまま）。「ビフォー」の元になる試作ページ自体は、このフォルダに入れていない。
- `display_*.png` は、ヘッドレス Chrome（ソフトウェア描画）で撮っている。実機の見た目と細部がずれる可能性がある。比較には `gui_layer_*.png`（画素が確定している）を主に使う。
