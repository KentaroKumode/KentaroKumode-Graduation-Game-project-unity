# GUI の元素材（PNG）

試作テスター（`docs/design/map-prototype.html`）と、単体のデモ（`gui-gold-pot.html`）が使う GUI の絵の**元**。
HTML の中には data URI（文字列）として埋め込んであるが、**元の PNG はここが正本**。差し替えたら、HTML の該当する data URI も更新する。

画像はすべて 480×270 の液晶（GUI の格子）に重ねるための、dot 単位のドット絵。拡大は整数倍のみ。

## GOLD の入れ物（76×96・同じ座標系の 6 層）

重ね順は **上から 4・2・5・3・1**（描画は 1→3→5→2→4。2026-10-13 に修正: 金貨の層 3 は、開口の下縁の層 5 とフレームの層 2 の後ろ）。層 3 だけが GOLD の量で上下する。閉じるときは 5・4・3・1 の y を上げ（層 2 は動かさない）、全閉の上げ幅は 42 dot。

## 旧表示の物資 GUI（今は使っていない・パス指定で運用）

試作テスターの旧表示（`drawSupplyGui`）が使う 8 枚。**元の PNG が無かった**ので、2026-10-13 に HTML の埋め込みから取り出してここに置き、HTML からは**相対パス（`gui/…`）で読む**ようにした。差し替えるときは、この PNG を直せば反映される（data URI の更新は要らない）。
`file://` で開いた HTML から読むと、画像を描いたキャンバスは「汚染」扱いになる（読み戻しや WebGL への転送ができない）。旧表示は今の画面では使われないので問題ないが、使い直すなら、ローカルサーバー経由で開くこと。

| ファイル | 中身 |
|---|---|
| `supply_old_frame.png` | 外枠（480×270） |
| `supply_old_back.png` | バーの裏地（480×270） |
| `supply_old_bar.png` | バー本体（480×270・左から割合ぶんだけ見せる） |
| `supply_old_number.png` | 数字アトラス（480×270・5×7・1,2,…,9,0） |
| `supply_lamp_half_off.png` `_on.png` | HALF（50% 未満）ランプの消灯・点灯（43×21） |
| `supply_lamp_crit_off.png` `_on.png` | CRIT（20% 未満）ランプの消灯・点灯（43×21） |

3 枚とも 300×300 の同じ座標系。画面へは (+180, +116) ずらして置く（飛び出す板の下端が画面の下、土台が画面の右端に接する）。

|---|---|---|

| `res_bar_extension.png` | 土台の裏からバネで飛び出す板。窓と、CRIT／HALF のランプ枠（赤・橙のベタ = 37×15。旧表示の `supply_lamp_*.png` を重ねる）つき | x 0〜289・y 109〜153（290×45） |
| `res_bar_extension_clean.png` | 上の汚す前の原本（描き直し用）。汚し版は `Tools/dirty_plate.py clean.png out.png --seed 3` で作る。輪郭（アルファ）・ランプ枠・窓は変えない | 同上 |
| `res_bar_fill.png` | 窓に入るバー本体（金色）。値の割合ぶんだけ、左から見せる | x 87〜237・y 133〜145（151×13） |
