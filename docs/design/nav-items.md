# 航行アイテム 設計図（2026-09-28・未実装）

自由移動のマップ（GAME.md §5）に合わせた航行系アイテムの設計図。**まだどこにも実装していない**。
数値はすべて仮置き（§23-21 と同じ扱い）。items.json へ入れる時に GAME.md §9 / §23 へ移し、この文書は消す。

## 方針

1. **「数値を少し足す」だけの品は作らない。** 〈四歩返しの杖飾り〉（移動時 25% で希望 +1）は弱すぎて削除済み（§24）。
   航行の品は、道か道の外か・照明を焚くか・逃げるか戦うか・補給庫を狙うか、といった**判断そのもの**を動かす。
2. **追跡の緊張を壊さない。** 「道の外へ逃げれば必ず振り切れる」を、追跡中の見失いにくさ（察知距離 +1.5・見失うまで 5 手番）で
   直したばかり。「気配が常に 0」「敵が常に見える」の類は入れない。
3. **上位のレアほど規則を変える。** BRONZE / SILVER は比率の調整、GOLD は選択肢を増やす、LEGENDARY は規則を変える。
4. **id = 表示名。** 家系を持たせる場合は `family` / `tier` で持ち、名前から構造を読み取らない（CLAUDE.md）。
   ロジック分岐に使う id は `Ids.cs`（`ItemIds`）に定数を足してから参照する。

### 細則

- **物資の購入金額 −50%**: ショップの `consFamily = "provision"` の品（湯気の立つ椀・古い手紙・凱旋の記憶・希望の欠片）の値段に掛ける。
  指輪と割符を両方持っても **−50% のまま（重ねない）** とする案。重ねると物資がほぼ無料になる。
- **煙玉**: 「各層 1 回」はパッシブの内部状態（層に入る時に戻す）。祭壇は追跡に移った時にしか撃たないので、煙玉が効くと初弾も出ない。
  発動した時はログと効果音で必ず知らせる（黙って消費されると持っている意味が伝わらない）。
- **前哨の旗**: 拠点の範囲で敵が初めて見えた時に時間を止めるかは要検討（止めると見張りとして強く、止めないと見落とす）。
  拠点は層を出ると消える。
- **地図売りの走り書き**: 公開は層に入った時の 1 回だけ。層の途中で手に入れた場合は次の層から。

## 実装の当たり（C#）

| 品 | 触る場所 |
|---|---|
| 油布の靴 | `FreeMapSim` の移動費用（`FreeMapParams.CostOffRoad` を使う所） |
| 魔石の欠片 | 魔石の判定（`VisionStone`）と BOT の `FreeNavBelief`（`VisionStone` を直接読んでいる） |
| 羅針の針 | `StoneBearing` / `BearingOf` / `BearingVector` を 6 → 12 分割対応に。`FreeNavBelief.BearingEstimate` も |
| 忍びの外套 | 速さの時間倍率（忍び足） |
| 鏡の護符 | 使い魔の探知（`FamiliarDetectRange`） |
| 夜目の指輪 | 視界（`VisionNone`）。使い魔が見えた時の停止もこの値で判定している |
| 補給商の割符 | 補給庫の報酬（`RewardCache`）と物音（`CacheNoise`） |
| 渡り鳥の羅盤 | 移動費用（行き先 ＝ `layout.goal` の時） |
| 逃げ足の護符 | `GameManager.FreeMap` の逃げる処理 |
| 追っ手殺しの刃 | 連戦の回数と報酬（`RewardGauntlet`） |
| 煙玉 | `FreeMapSim` の察知 → 追跡へ移る分岐。層ごとの使用済みフラグ |
| 地図売りの走り書き | 層の生成直後に点の公開（`known`）を立てる |
| 前哨の旗 | 拠点の位置を `FreeMapSim` に持たせ、毎刻みに公開と目視の判定。UI にボタンが要る |
| 購入金額 −50% | ショップの値段計算（`consFamily == "provision"`） |

- パッシブの効果は `FreeMapSim` へ**係数の構造体**（視界・魔石の範囲・道の外の費用倍率・…）として渡し、
  Sim の中でアイテム id を見ない（純 C# のまま・テストしやすい）。
- **前提**: 試作 HTML で先に入れた変更（追跡中の察知 +1.5・見失うまで 5 手番・行き止まりを潰す生成・層の拡大・性質 7 種）は
  まだ C# に移していない。アイテムはその後に載せる。

## 測り方

1. **BOT が値打ちを測れるようにする。** アイテムの序列（§21-1）は戦闘の強さで測るので、航行の品は価値ゼロと見なされ BOT が買わない。
   航行 BOT（`FreeNavPlanner`）の評価に効果を入れた上で、**付けた時と付けない時**の踏破率・層を抜けた時の物資・捕まる率を比べる。
2. **発動率を先に数える**（棄却記録の原則①）。煙玉・逃げ足の護符・前哨の旗は、使われる場面が少なければ〈四歩返し〉と同じになる。
3. 数値を詰めるのは発動率を見てから。
