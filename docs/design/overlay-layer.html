DICE BOUND — オーバーレイ層設計図

条件出現ボタン・GUI レール・一時 UI の仕様 · 筐体の静的レイアウトは cabinet-layout.html · 2026-07-24
層の定義: 本書が扱うのは「常時は存在せず、条件や操作で現れて消えるもの」。 筐体に常設される計器・スロット・スリットの位置は cabinet-layout.html §2 が正本。 本書はそれらの出現状態・アニメーション・操作仕様を持つ。

§1 ボタン井戸 — ロール⇄バトルの出現機構

井戸 (cabinet §2 #17: 1574,734 · 112×112 角丸) をロールボタンとバトルボタン (配線決定) が共有し、 条件を満たした方だけが下からせり上がる。同時に 2 つ出ることは構造上ない = 誤操作を機構で防止。

2 つのボタンの識別 (刻印なし・どちらも四角)

ボタン形状色出現条件押した結果
ロール角丸四角 96×96 (角R=8)琥珀 #E8B860 + 内部白熱グロー自ターン開始 (入力受付開始)ダイスシャッフル開始 (cabinet §4) → ボタンは沈んで井戸が閉じる
バトル角丸四角 96×96 (角R=8) + 外周発光リング深橙 #D9713D、リングが明滅ロール済み かつ 全有効ダイスが端子に割当済み相互攻撃解決 → 沈む。敵処理中は井戸閉のまま

識別は色 + 外周リングの有無。井戸も四角 (112×112・角R=12)。

出現/沈降アニメーション (24fps)

動作フレーム挙動
せり上がり10f井戸内から 20px 上昇。終端で 2px オーバーシュート → 2f で着座 (機械の「ガチャン」感)
押し込み3fストローク 8px 沈む + 発光が一瞬強まる
沈降 (退場)8f井戸面と面一まで下降 → 井戸のアイリスシャッタが 4f で閉じる
入れ替わり計 22fロール沈降 (8f) → 間 2f → バトルせり上がり (10f+2f)。配線が既に完了していれば連続再生

状態規則

  • 配線が未完了のままロール済み → 井戸は閉じたまま。全ダイス割当が完了した瞬間にバトルボタンがせり上がる
  • バトルボタン出現後も配線変更は可能。変更で割当が不完全になったら 8f で再沈降 (押せない状態が形で分かる)
  • リロール実行中・シャッフル演出中・敵処理中は両ボタンとも収納
  • 戦闘外 (マップ/ショップ) では井戸は常時閉。シャッタ面はシャーシと同素材

§2 インベントリ GUI レール (パッシブ + 消費の 2 段)

筐体には固定ラックを持たない。所持品は上端スリット (cabinet §2 #18) から降りてくる 2 段レールで閲覧・操作する。 レール自体は「筐体からせり出す機械」の見た目だが、挙動は GUI (スクロール・即時開閉)。

§3 オーバーレイ層の共通規則

規則内容
z 順序卓上小物 < 筐体 < LCD < 常設計器 < 出現ボタン < GUI レール < 確認ダイアログ (LCD 内)
同時出現GUI レールとボタン井戸は共存可。レール展開中にボタンを押すとレールは強制収納→ボタン処理
機械語彙すべてのオーバーレイは「筐体からせり出す機構」として描く (フェード/スライドインの GUI 的表現は禁止)。出現 10f + 2px オーバーシュートの「ガチャン」を共通言語にする
刻印禁止筐体と同じ。文字はニキシー数字のみ。tooltip/確認テキストは LCD 内に出す
演出中ロックシャッフル・戦闘解決・LCD トランジション中は全オーバーレイ操作不可 + 強制収納
将来枠タブ的な切替 (コーデックス/スキルツリー等) を筐体に足す場合も本書に追記し、同じ出現語彙に従う
