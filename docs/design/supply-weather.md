# 補給・輸送・天候 設計図（2026-09-28 起草・2026-10-03 検討反映・未実装）

自由移動マップ（GAME.md §5）の物資まわりを作り直す案。**まだどこにも実装していない**。数値はすべて叩き台。
採用が決まったら GAME.md（§5-7 / §10 / §15-1 / §16 / §23-21）へ移し、この文書は消す。

**2026-10-03 ユーザー判断: 実装はまだしない。** 実装して測ってもバランスは完成までズレ続けるので、
今は設計を固めるだけにする。

## 解きたい問題

1. **物資を貯める得がない。** 751 以上（充足）はいくら多くても同じで、困るのは 450 を切ってから。
2. **時間とともに悪くなる感触が薄い。** 物資が減るのは歩いた距離の分だけで、時間とは結びついていない。
3. **消費を増やすと詰む。** Highfleet と違って補給地点を選べない。

「消費を増やす」は場当たり的対処になる（補給の少なさが先に効いて詰む）ので採らない。
代わりに **補給の密度・航続距離・時間で悪化する環境** の 3 つを組み替える。

## 1. 戦闘の後に開く店

- **戦闘・エリートに勝つと、50% でその場に店が開く。** 片付けた瞬間に開き、その場で使う（戻ってくる前提にしない）。
  イベント・秘宝・補給庫・休憩の点は対象外。
- **種類は完全ランダムで 3 種**（2026-10-03: 補給拠点と消耗品屋を統合）。

| 種類 | 重み（仮） | 得意な品 | 他の品 |
|---|---:|---|---|
| 補給拠点 | 60 | 物資（在庫 大・安い）・消耗品（系統ごとに保証）・囮・罠 | パッシブ 1〜2 |
| 遺物商 | 25 | パッシブ（**レアリティ表の優遇＋在庫数の優遇**） | 物資 小 |
| 鍛冶屋 | 15 | **武器（鍛冶屋でだけ売る）**・強化素材（在庫が最も多い）・**出目パーツ** | パッシブ 1〜2・物資 小 |

- **パッシブは全店に 1〜2 枠置く**（2026-10-03 決定）。パッシブ購入数がクリア率の主要駆動源
  （GAME.md §16-1: 7.30 → 9.37 個で 57.8% → 68.3%）なので、遺物商が出たかどうかの運に直結させない。
  遺物商はその上でレアリティと在庫数で優遇する。
- **出目パーツは鍛冶屋で売る**（2026-10-03 決定）。
- 強化素材は鍛冶屋が最も多く、他の店にも少しだけ置く。
- **物資は店ごとに在庫と値段が固定**（無限には買えない）。10 単位で好きな量を買う。種類で在庫・値段を変える（補給拠点が大きく安い）。
- 1 店あたりの枠は減らし、**リロールは廃止**。
- 層全体で目に入る品の数は **おおまかに今と同じくらい** でよい（2026-10-03: 今は合わせ込まない。完成までバランスはズレ続ける）。

### 補給には時間がかかる（2026-10-03 ユーザー案）

- **物資を補給すると、一定時間その場で動けない**（時間は流れ続け、徘徊エネミーも動く）。
- **時間は量によらず一定**（案: 1 回 1 手番）。量に比例させると、タンクの大きい輸送振りほど満タンにするのが遅くなり、狙いと逆になる。
  一定なら、小分けに何度も補給する輸送 0 だけが時間を多く払う。
- 狙い: 輸送 0 は頻繁に補給を要求されるので、**追跡されていても補給しなければならない**場面が生まれる。
  追跡中の敵は 1 手番に距離 1.0 進むので、1 手番止まれば距離 1 ぶん詰められる。
- 任意: 補給で小さな物音を立てる。囮で逸らしてから補給する、という使い方が生まれる。

### 強盗（強奪 r10）の作り直し

店が戦闘の後に確率で開くと、今の罰（残りの店の値段 ×2）は「残りの店」が決まらず、1 回限りの店ではコスト 0 になる。

- **罰は「周辺の店のコスト 2 倍」にする**（2026-10-03 決定）。「周辺」の範囲（距離・層全体か）は未定。
- **ゴールドの強奪は無し、または大幅に弱くする。**
- 商才（店 1 軒の特売枠 +1/段）も 1 軒あたりの枠が減ると効き方が変わる。数値は店の枠数と一緒に決める。

## 2. 物資の持ち越し

- **物資は層をまたいで持ち越す。** 前の層で余らせた分がそのまま次の層の出発点になる。
- 持ち越しがあるので、前哨基地の補給（今は +200）は減らしてよいかもしれない（要測定）。

## 3. 輸送（〈燈火〉を作り替える）

- 整備パネル（GAME.md §15-1・予算 24pt 固定）の **〈燈火〉を〈輸送〉に作り替える**。新しい枠は足さない
  （§23-21 に残っている「照明と名前が紛らわしい」問題も同時に片付く）。
- 段効果（案）: 物資の上限 +N/段・店での物資の買値 −X%/段。極点（r10）は未定。
- **駆け引き:** 輸送に振るほど戦闘の段（外殻・出力など）が減る。
  - **輸送 0:** 航続距離が短い → 補給のためによく戦う → 店をたくさん見て力を集める。HP は削れ、
    **追跡されていても補給のために足を止める**場面が増える。
  - **輸送を振り切る:** 航続距離が長い → 戦闘を選んで避け、早く抜ける。補給の回数が少なく、足を止める時を選べる。力は控えめ。
- **航続距離の価値は「追加の報酬」ではなく、次の 3 つで払う**（Highfleet の燃料と同じ）:
  - **速攻:** 寄り道せずに出口まで一気に行ける。
  - **撤退:** 天候が崩れた時、予定を捨てて道の外をまっすぐ出口へ抜けられる。保険があるので少し欲張った寄り道もできる。
  - **安全:** 補給で足を止める回数が少なく、止まる時を選べる。
- **力の綱引き:** 輸送に振るほど戦闘が減る → 開く店が減る → パッシブが減る（振らない理由）。
  補給の手間・撤退・予報（振る理由）。どちらが勝つかは測るまで分からない。
- **税金化も死に枠化もさせない条件:** 輸送 0 でも「たくさん戦ってたくさん買う」道で勝てること、
  振り切りでも「避けて抜ける」道で勝てること。§23-7（メタバフの寄与が大きすぎる）を悪化させないこと。

## 4. 物資の段階が効くもの（2026-10-03 決定）

- **物資のデバフ（疲労・苦悩・迷妄）は廃止する。** 物資が少ない時の罰を重ねすぎないため。
  影響: `CombatManager` の疲労 2 か所・苦悩・迷妄、`ProvisionSystem` の定数、DAMAGE_CALC_REFERENCE.md の疲労の行。
- **残すもの:**
  - **戦闘の被弾損**（段階依存 −40〜−100）は残す。
  - **予報の精度**（下の §5）は物資の段階で変える。
  - §5-7 の天候の善し悪しの確率（物資が多いほど穏やか）。

## 5. 時間で進む天候（§5-7 異常現象の作り替え）

- 今の §5-7 は層に入った時に 1〜2 件を引いて層の間は変わらない。これを **層の中の時間とともに段階が進む天候** にする。
  - 層に入った直後は穏やか。数手番ごとに前線が近づき、段階が上がるか現象が重なる。
  - **層ごとにリセット**（次の層はまた穏やかから始まる）。層の深さで進み方を変えるのは可。
  - 世界観（GAME.md §19-2「大穴は日々拡大している」「深層の異常気象は狭間の物理が支配する」）とそのまま合う。
- 既存の 15 件を活かし、**航行向けの効果**を足す。**下の 7 種を一旦すべて入れ、遊んで削る**（2026-10-03 決定）:

| 現象 | 航行への効果（案） |
|---|---|
| 霧（新） | 見える範囲と魔石の範囲が縮む |
| 沈む静寂 | 足音や物音が遠くまで届く |
| 削る砂 | 道の外の物資コストが上がる。代わりに足跡がすぐ消える |
| 朱の雪 | 移動に時間がかかる |
| 落石のような雹 | 道の外を歩くと HP が削れる |
| 崩れる地平 | 時間とともに道が崩れて消える |
| 沈み続ける湖面 | 時間とともに点が沈んで消える（未使用の店・戦闘も） |

  「崩れる地平」「沈み続ける湖面」は 3 列マップでは地図の仕組みを広げないと入らず未実装だったが、自由移動なら点や道を消すだけで入る。
  「崩れる地平」は実質「時間とともに消費を増やす」ので、下の「出口まで道の外で行ける経路を残す」保証が必須。
- **予報を見せる。** 筐体に気圧計のような計器を置き、今の段階と次の段階までの目安を出す
  （2026-10-03: 筐体の引き出しには敵の名前やパッシブの説明も出ており、天候の語彙も同じ扱いで画中画の原則に反しない）。
  **精度は物資の段階で変わる**（嘘は出さず、ぼやけるだけ）:

| 物資の段階 | 予報 |
|---|---|
| 充足 | 次の段階まで何手番か、次に来る現象の名前まで |
| 目減り | 手番は幅付き（例: 3〜5 手番後）、現象は種類だけ |
| 枯渇し始める | 「近い / まだ遠い」だけ |
| 枯渇寸前・払底 | 針が暴れて読めない |

- **既存の仕組みとの噛み合い:** §5-7 は現象の善し悪しの確率が層に入った時の物資で決まる（多いほど穏やか）。
  持ち越しと輸送があると、**物資をたっぷり運んで層に入った人ほど天候に恵まれる**。
- **ボスには触らない。** ボスの自動調整（L3・隠し倍率禁止・GAME.md §13-3）と衝突しない。

### 死の螺旋を防ぐ

物資が少ない → 予報が読めない・荒れた現象が出やすい・撤退できない → 悪天候に捕まる → さらに減る、の悪循環は
緊張の源だが、抜けられない螺旋にはしない（§15-1 オーバーロードの注意書きと同じ問題）。
物資のデバフを廃止したので、少ない時の罰は「被弾損・予報・天候の確率」の 3 つに減った。

- 層ごとのリセットで悪循環は 1 層で切れる。
- 道が崩れても、**出口まで道の外で行ける経路は必ず残す**。
- 物資 0 で層に入っても、最初の数歩を踏み出せる量は前哨基地で保証する。

## 6. 燃料計の表示

物資の段階（GAME.md §10-1）を燃料計に 4 段で表示する。予報の精度がこの段階で変わるので、段階はプレイヤーに見せる。

| 物資 | 表示 |
|---|---|
| 751〜1000 | FULL |
| 451〜750 | HALF |
| 201〜450 | LOW |
| 1〜200 | CRIT |
| 0（払底） | 未定（HP で払う別の状態に入るので、CRIT の点滅より別表記 EMPTY が候補） |

## 検討して落とした案

| 案 | 落とした理由 |
|---|---|
| 物資の消費を大きく増やす | 補給地点を選べないので詰む。場当たり的対処 |
| 入植した街が数手番後に建つ（時間差） | 追跡からの回避・5 層と重なってテンポが悪い。そもそも同じ街に戻らない |
| 放っておいた街が徘徊エネミーに襲われる | 同じ街に戻らないので意味がない |
| 街を安全地帯（隠れ家）にする | 安全すぎる。抑えの待ち伏せも運の要素が強い |
| 遠くにしか無い高価値の点（航続距離の報酬） | 悪用されるか弱すぎるかの二択になる |
| 戦う相手を選べることを航続距離の価値にする | 選べるかどうかは視野（照明・偵察）の問題で、航続距離では買えない |
| エリートの報酬を上げて「数より質」の道を作る | 強い戦闘ビルドに荒らされる |
| ボスが時間で強くなる | ボス自体ではなく環境の悪化で表現する（天候）方がよい。L3 の規約とも衝突しない |
| **BINGO 警告**（最寄りの補給点までの最短経路＋余裕を物資が下回ったら警告灯・NO RETURN） | 2026-10-03 ユーザー判断で不要。補給点が前哨基地しか無い層の序盤は後ろを指し続け、持ち越しで少なく入ると入った瞬間から点く |
| 出口までの物資を BINGO にする | 満タンでも出口に届かない層では常に下回る無意味な指標になる |
| 航続圏を地図に描く（届く点の塗り分け・帰れない一線の黄色） | 経路が複雑になり説明できない。途中の点を踏むと発動する。常に表示すると後ろへ下がれと言い続ける |
| 経由ルートを線で見せてボタンで実行する | 毎回の航行判断が重くなりすぎる |
| 物資を距離だけにして、道の得を時間に移す（航続圏を円にする） | 手触りの土台が大きく変わる割に得が薄い |
| 余った物資を層の終わりに換金する | 保留。持ち越しを採用 |
| **物資のデバフ（疲労・苦悩・迷妄）を残す** | 2026-10-03 廃止。少ない時の罰が被弾損・予報・天候の確率と 4 重に重なる |
| **店を 4 種（補給拠点・消耗品屋を別）** | 2026-10-03 統合して 3 種に |
| **パッシブを遺物商だけで売る** | パッシブ購入数がクリア率を支配するので、遺物商が出たかの運に直結する。全店に 1〜2 枠 |

## 測り方（BOT）── 実装してから

- **輸送 0 / 5 / 10** で比べる: 7 層クリア率が近い範囲に収まるか、層ごとの補給回数、層を抜けた時の物資、捕まる率、
  **補給で足を止めている間に捕まった回数**。
- 層を抜けた時の物資の分布（目安: 中央値が上限の半分前後で、ばらつきがある）。
- 天候の段階が何段目まで進んでから層を抜けているか。撤退（予定を捨てて出口へ向かう）が実際に起きているか。
- BOT の航行（`FreeNavPlanner`）には、店の在庫・天候の予報・物資の持ち越し・補給で止まる時間を評価に入れる必要がある。
  天候は予報と撤退の判断が入るまで BOT では測れないので、店・持ち越し・輸送を先に測る。

## 決まっていないこと

- 天候の段階の進み方（何手番ごとか・層の深さで速めるか）と、各段階で何が起きるか。
- 店の枠数・物資の在庫と値段・重みの具体的な数値。
- 補給で動けない時間（案 1 手番）と、物音を立てるか。
- 強盗の「周辺」の範囲と、ゴールド強奪を無しにするか弱めるか。
- 〈輸送〉の段効果の数値と極点（r10）。
- 遠くの宝の中身をどうするか（案自体を落としたので、戦利品の設計として別に扱うかどうか）。
- 前哨基地の補給量（持ち越しとの兼ね合い）。
- 払底の燃料計の表記。
- 挑戦デバフ〈戦場の霧〉/〈暗夜〉（§23-21 で未決）を、天候の「霧」と統合するか。
