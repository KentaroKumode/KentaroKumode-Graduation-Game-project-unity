# 補給・輸送・天候 設計図（2026-09-28・未実装）

自由移動マップ（GAME.md §5）の物資まわりを作り直す案。**まだどこにも実装していない**。数値はすべて叩き台。
採用が決まったら GAME.md（§5-7 / §10 / §15-1 / §16 / §23-21）へ移し、この文書は消す。

## 解きたい問題

1. **物資を貯める得がない。** 751 以上（充足）はいくら多くても同じで、困るのは 450 を切ってから。
2. **時間とともに悪くなる感触が薄い。** 物資が減るのは歩いた距離の分だけで、時間とは結びついていない。
3. **消費を増やすと詰む。** Highfleet と違って補給地点を選べない。

「消費を増やす」は場当たり的対処になる（補給の少なさが先に効いて詰む）ので採らない。
代わりに **補給の密度・航続距離・時間で悪化する環境** の 3 つを組み替える。

## 1. 戦闘の後に開く店

- **戦闘・エリートに勝つと、50% でその場に店が開く。** 片付けた瞬間に開き、その場で使う（戻ってくる前提にしない）。
  イベント・秘宝・補給庫・休憩の点は対象外。
- **種類は完全ランダム**で 4 種。どの店にも他の品が少しはあるが、得意な品で優遇される。

| 種類 | 重み（仮） | 得意な品 | 他の品 |
|---|---:|---|---|
| 補給拠点 | 35 | 物資（在庫 大・安い） | 消耗品 少 |
| 消耗品屋 | 25 | 消耗品（系統ごとに保証）・囮・罠 | 物資 中 |
| 遺物商 | 25 | パッシブ（数・レアリティで優遇） | 物資 小 |
| 鍛冶屋 | 15 | **武器（鍛冶屋でだけ売る）**・強化素材（在庫が最も多い） | 物資 小 |

- 強化素材は鍛冶屋が最も多く、他の店にも少しだけ置く。
- **物資は店ごとに在庫と値段が固定**（無限には買えない）。10 単位で好きな量を買う。種類で在庫・値段を変える（補給拠点が大きく安い）。
- 1 店あたりの枠は減らし、**リロールは廃止**。
- **層全体で目に入る品の数は今と同じくらいに合わせる。** 根拠: パッシブ購入数がクリア率の主要駆動源
  （GAME.md §16-1: 7.30 → 9.37 個で 57.8% → 68.3%）、リロール 1 店 2 回で +6.4〜6.6pt。

## 2. 物資の持ち越し

- **物資は層をまたいで持ち越す。** 前の層で余らせた分がそのまま次の層の出発点になる。
- 持ち越しがあるので、前哨基地の補給（今は +200）は減らしてよいかもしれない（要測定）。

## 3. 輸送（〈燈火〉を作り替える）

- 整備パネル（GAME.md §15-1・予算 24pt 固定）の **〈燈火〉を〈輸送〉に作り替える**。新しい枠は足さない
  （§23-21 に残っている「照明と名前が紛らわしい」問題も同時に片付く）。
- 段効果（案）: 物資の上限 +N/段・店での物資の買値 −X%/段。極点（r10）は未定。
- **駆け引き:** 輸送に振るほど戦闘の段（外殻・出力など）が減る。
  - **輸送 0:** 航続距離が短い → 補給のためによく戦う → 店をたくさん見て力を集める。HP は削れる。
  - **輸送を振り切る:** 航続距離が長い → 戦闘を選んで避け、早く抜ける。力は控えめ。
- **航続距離の価値は「追加の報酬」ではなく、次の 2 つで払う**（Highfleet の燃料と同じ）:
  - **速攻:** 寄り道せずに出口まで一気に行ける。
  - **撤退:** 天候が崩れた時、予定を捨てて道の外をまっすぐ出口へ抜けられる。保険があるので少し欲張った寄り道もできる。
- **税金化させない条件:** 輸送 0 でも「たくさん戦ってたくさん買う」道で勝てること。
  §23-7（メタバフの寄与が大きすぎる）を悪化させないこと。

## 4. 時間で進む天候（§5-7 異常現象の作り替え）

- 今の §5-7 は層に入った時に 1〜2 件を引いて層の間は変わらない。これを **層の中の時間とともに段階が進む天候** にする。
  - 層に入った直後は穏やか。数手番ごとに前線が近づき、段階が上がるか現象が重なる。
  - **層ごとにリセット**（次の層はまた穏やかから始まる）。層の深さで進み方を変えるのは可。
  - 世界観（GAME.md §19-2「大穴は日々拡大している」「深層の異常気象は狭間の物理が支配する」）とそのまま合う。
- 既存の 15 件を活かし、**航行向けの効果**を足す（例）:

| 現象 | 航行への効果（案） |
|---|---|
| 霧（新） | 見える範囲と魔石の範囲が縮む |
| 沈む静寂 | 足音や物音が遠くまで届く |
| 削る砂 | 道の外の物資コストが上がる。代わりに足跡がすぐ消える |
| 朱の雪 | 移動に時間がかかる |
| 落石のような雹 | 道の外を歩くと HP が削れる |
| 崩れる地平 | 時間とともに道が崩れて消える |
| 沈み続ける湖面 | 時間とともに点が沈んで消える（未使用の店・戦闘も） |

  「崩れる地平」「沈み続ける湖面」は 3 列マップでは地図の仕組みを広げないと入らず未実装だったが、自由移動なら点や道を消すだけで入る。
- **予報を見せる。** 筐体に気圧計のような計器を置き、今の段階と次の段階までの目安を出す。
  **精度は物資の段階で変わる**（嘘は出さず、ぼやけるだけ）:

| 物資の段階 | 予報 |
|---|---|
| 充足 | 次の段階まで何手番か、次に来る現象の名前まで |
| 目減り | 手番は幅付き（例: 3〜5 手番後）、現象は種類だけ |
| 枯渇し始める | 「近い / まだ遠い」だけ |
| 枯渇寸前・払底 | 針が暴れて読めない |

- **既存の仕組みとの噛み合い:** §5-7 は現象の善し悪しの確率が層に入った時の物資で決まる（多いほど穏やか）。
  持ち越しと輸送があると、**物資をたっぷり運んで層に入った人ほど天候に恵まれる**。
- **ボスには触らない。** ボスの自動調整（L3・隠し倍率禁止・GAME.md §13-3）と衝突しない。

### 死の螺旋を防ぐ

物資が少ない → 予報が読めない・荒れた現象が出やすい・撤退できない → 悪天候に捕まる → さらに減る、の悪循環は
緊張の源だが、抜けられない螺旋にはしない（§15-1 オーバーロードの注意書きと同じ問題）。

- 層ごとのリセットで悪循環は 1 層で切れる。
- 道が崩れても、**出口まで道の外で行ける経路は必ず残す**。
- 物資 0 で層に入っても、最初の数歩を踏み出せる量は前哨基地で保証する。

## 検討して落とした案

| 案 | 落とした理由 |
|---|---|
| 物資の消費を大きく増やす | 補給地点を選べないので詰む。場当たり的対処 |
| 入植した街が数手番後に建つ（時間差） | 追跡からの回避・5 層と重なってテンポが悪い。そもそも同じ街に戻らない |
| 放っておいた街が徘徊エネミーに襲われる | 同じ街に戻らないので意味がない |
| 街を安全地帯（隠れ家）にする | 安全すぎる。抑えの待ち伏せも運の要素が強い |
| 遠くにしか無い高価値の点（航続距離の報酬） | 悪用されるか弱すぎるかの二択になる |
| 戦う相手を選べることを航続距離の価値にする | 選べるかどうかは視野（照明・偵察）の問題で、航続距離では買えない |
| エリートの報酬を上げて「数より質」の道を作る | 強い戦闘ビルドに荒らされる |
| ボスが時間で強くなる | ボス自体ではなく環境の悪化で表現する（天候）方がよい。L3 の規約とも衝突しない |
| 余った物資を層の終わりに換金する | 保留。持ち越しを採用 |

## 測り方（BOT）

- **輸送 0 / 5 / 10** で比べる: 7 層クリア率が近い範囲に収まるか、層ごとの補給回数、層を抜けた時の物資、捕まる率。
- 層を抜けた時の物資の分布（目安: 中央値が上限の半分前後で、ばらつきがある）。
- 天候の段階が何段目まで進んでから層を抜けているか。撤退（予定を捨てて出口へ向かう）が実際に起きているか。
- 層全体で目に入った品の数が、今と同じくらいか。
- BOT の航行（`FreeNavPlanner`）には、店の在庫・天候の予報・物資の持ち越しを評価に入れる必要がある。

## 決まっていないこと

- 天候の段階の進み方（何手番ごとか・層の深さで速めるか）と、各段階で何が起きるか。
- 店の枠数・物資の在庫と値段・重みの具体的な数値。
- 〈輸送〉の段効果の数値と極点（r10）。
- 遠くの宝の中身をどうするか（案自体を落としたので、戦利品の設計として別に扱うかどうか）。
- 前哨基地の補給量（持ち越しとの兼ね合い）。
- 挑戦デバフ〈戦場の霧〉/〈暗夜〉（§23-21 で未決）を、天候の「霧」と統合するか。
