# コンボピック 15 品（2026-10-04・実装済み・未測定）

「単品では地味で、相方を拾うと成立する」パッシブ。正本は実コード（`Effects/ComboPickEffects.cs`・`items.json`）。
数値は叩き台で、**測定するまで動かさない**（発動率を先に数える）。

## 設計の方針

- 資源を返すだけ・既存の間口を広げるだけの案は採らない。**成立すると跳ね上がる**ものにする。
  互いが互いを何度も引き起こす「輪」と、入口を足して出口を太くする「組」の 2 種類。
- **決定的に毎ターン乗る**（確率で当たる火力は分散に埋もれる・design-rejects の判断原則 2）。
- 歯止めは**実数で書く**（上限・ボスの割合・ターン内の発動回数）。隠し倍率は使わない（CLAUDE.md・§13-3）。
- 新規 1 品は単体でも弱く効く。相方を拾って初めて跳ね上がる。

## 実装の足場（CombatContext の入口）

「〜が付くたび」は入口で数える。効果クラスは**ルールのフラグを代入する**だけ（戦闘開始に何度呼ばれても結果が同じ）。

| 入口 | 数えるもの |
|---|---|
| `AddEnemyBleed` | `bleedApplications`（付与の回数）。**特殊端子の出血が入口を通っていなかった**ので通すように直した |
| `AddStatus`（毒） | 毒が**実際に増えた**時だけ `poisonIncreases` と充電。上限に張り付いた分は数えない（数えると輪が止まらない） |
| `MultiplyEnemyPoison` | 倍化。AddStatus を通さない（メタ「毒 r2 濃縮」の+N を倍化に上乗せさせない） |
| `GainShield` | シールド獲得の**唯一の入口**。12 本に散っていた `consShield += …; shieldGainedTotal += …` をすべてここへ寄せた。〈煮詰めた毒の膠〉の上乗せもここ |
| `SelfInflictHpLoss` | 自傷。`CombatManager.LoseHpKeepOne`（HP 1 が床・「審判」の被ダメ増加を通さない） |
| `ProcessDamage` | `playerCritThisTurn`（`isCritical` は同ターンの敵の攻撃で false に上書きされるため別に持つ）・`hpLossEventsThisTurn` |
| `CombatManager.BleedTickDamage` | 新旧パイプラインで 4 か所に散っていた出血ダメージの解決を 1 つにまとめた。〈血の祝祭〉の 2 回目はここ |
| `RerollPhase` | リロールの 1 回ごとに毒針の毒（無料リロールも 1 回に数える） |

## 既知の制約・要確認

- **新パイプライン（`UseMutualAttackPipeline` 既定 true）が対象。** 旧パイプラインでは予告攻撃の値（`telegraphedEnemyAttack`）が入らないので〈開き直りの胸当て〉は発動しない。
  出血の 2 回目（血の祝祭）と各入口は新旧共通。
- 〈錆びた留め金〉は「ターン頭の残り＋獲得−ターン末の残り」の差分で測る。シールドが減る経路は書き換え箇所が散っていて入口が無いため。
  失効（`consShieldExpireTurn`）による減りも数える。取り戻しは 2 以上減った時から（半分が 1 以上になる）。
- 〈毒殺者〉（石抜きの毒指輪）の「敵 HP×20%」は**最大 HP 基準**（docs の記述どおり。コードのコメントは「現在」と食い違っていた）。脱皮する毒壺は現在 HP 基準で別に書いた。
- 〈振り直しの毒針〉は単体でも強い恐れがある（リロール 5 回で毒 5 → 毒殺者）。測定対象。
- 〈血契の釘〉と〈死に際の算盤〉と〈刃毀れの鑢〉と〈血の帳簿〉を全部拾うと、1 ターンに攻撃が約 +3 ずつ積み上がる（帳簿の上限+10 が止める）。
- **BOT は組の価値を測れない**（1 品ずつの評価だと片方は価値が低く見える。航行アイテムと同じ問題）。`AutoTest/BuildSynergy.cs` へ登録する余地がある。

## 測り方

1. **発動率を先に数える**（成立率）: 輪が実際に回ったターン数・戦闘数。
2. **成立した時のクリア率**と、**成立しなかった時**の差。単品で拾った時に損をしていないこと。
3. 〈触媒の坩堝〉＋〈脱皮する毒壺〉＋〈石抜きの毒指輪〉: 毒殺がいつ何回撃たれ、ボス戦で何ターンで削り切るか。
4. 〈共鳴する炉心〉: 爆発が何ターン連続したか・充電がリロールに回らなくなって負けていないか。
