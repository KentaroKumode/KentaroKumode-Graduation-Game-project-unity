つながり

左の高い箱（HP の数字）から低い溝が伸び、溝の先は右の可動箱の中に巻き込まれている。可動箱と物資のバーは、同じレールに乗っている。

航行

可動箱は左寄り。溝は短く、HP のバーは 0 に近い側だけが見える。HP が多い間はバーが箱の中まで続き、減ってくると先端が見えてくる。可動箱の割合と警告ランプで、HP は控えめに読める。

戦闘

物資のバーがレールから外れて下へ抜ける → 空いたレールを可動箱が右端まで走る → 溝が全長まで引き出され、HP のバーが全部見える。戻る時は逆の順番。
