# GUI の実装状況（2026-10-13）

**基準: GUI として存在しているか。** 試作 HTML（`docs/design/map-prototype.html`）の液晶に、絵や演出として組まれているものを「実装済み」とする。
HTML の文字・ボタン（液晶の外の欄）だけで出しているものは「未実装」。ゲーム本体（Unity）に既にある表示は「実装済み（既存）」。

**仮置きは「実装済み」に含めない。** 見た目が仮の絵・コード描画の代用・見本の値のままで本物につないでいないものは、仮置きが動いていても「未実装」に数える（下の「未実装のうち仮置きがあるもの」に一覧）。

番号（#）は `gui-full-layout.html` の番号と同じ。番号は変えない。

- 液晶は 480×270 の格子、拡大は整数倍のみ。ピクセル要素の状態表現に `localScale` を使わない。
- 画中画の原則: 液晶の外（筐体・計器盤）はロアに関与させない。メカの語彙だけを使う。
- 廃止済み（数えない）: パッシブのスティック挿し／武器・ダイスの物理ソケット／地図⇄戦闘の切り替えボタン／「希望」ゲージ（物資へ統合）。
- 絵の元素材（PNG）は [`gui/`](gui/README.md) が正本。

# 付録: Unity 2D 版の仮置き実装と素材の対応（2026-10-24）

上の「未実装」のうち、画面の骨格だけ Unity（`Game2D.unity`・LCD クアッド＋ Canvas）へ**仮置き**で組んだ。中身の値・名前は見本で、ゲームの状態には未接続（注記のあるものを除く）。
実装は `Assets/Scripts/UI/Game2D/`（`Screens/` ＝ 共通キット・モーダル・航行の計器、`Game2DBattleHud.cs` ＝ 戦闘 HUD）。

## 概要

- **共通キット**（`Screens/Game2DKit.cs`）: 生成素材の台・行・タブ・ボタン・スロット・ランプ・ダイスの面・アイコンを、**加工せず**最近傍で大きさだけ合わせて打つ。文字は 3×5 のドット字（英数字のみ）。
- **モーダル 13 画面**（`Screens/Game2DScreens.cs`）: ショップ(#34・#35)・イベント・報酬・休憩・秘宝・補給拠点・〈門〉・整備パネル(#39)・エンディング(#40)・設定(#41)・所持品(#31・#32)・敵の詳細・脱出の確認(#19)。開いている間は地図・ナビ・戦闘のクリックを止める。
- **航行の計器**（`Screens/Game2DNavExtras.cs`）: 上の帯 ＝ 気圧計(#6)のみ／左下 ＝ 所持品の欄(#31・消耗品とパッシブを統合)／右 ＝ 航行アイテム 3 枠(#20)。待つ・脱出ボタン、層・職業・状態異常・警告ランプの表示は置かない（決定済み）。
- **戦闘 HUD**（`Game2DBattleHud.cs`）: ダイスのロール・端子への配線・決定ボタン・充電ランプ(#25)・エスカレーションランプ(#26)・敵 HP。見本の動きで、`CombatManager` にはつないでいない。

## 方針の変更

- **階層表示は不要**（#37 は作らない）。航行の上の帯からは外し、気圧計だけを残す。
- 生成した素材は**加工しない**（文字消し・着色・明るさ増し・回転・色替えをしない）。色の違いは、参考画像の切り抜きを変えて生成し分ける。
- 生成は 1 部品あたり多くて 3 回で打ち切り、最良を仮置きとして次へ進む。

## 素材の対応（生成物）

生成は PixelLab（`/generate-ui-v2`）。参考画像 `images/43.png` の切り抜き＋そのパレットを渡し、文は `Generate {X} based on the design and colors of the reference image.` の 1 文のみ。
生データと発注の一覧は [`Tools/gui_gen/`](../../Tools/gui_gen/)（`manifest.py` ＝ 発注一覧、`out/<部品名>/a<n>/NN.png` ＝ 候補）。採用したものは `Assets/gui2d/battle_ui/`。

## 注釈（未解決・要判断）

1. **見出しアイコン 8 種が未生成**: `shop` `event` `elite` `rest` `treasure` `depot` `unknown`（ショップの MAP FRAGMENT 行も同じ）。現状は地図のノード用の 17×17・1 色の絵をコードで塗って代用している。生成の対象にするかを決める。
2. **気圧計の台が専用素材ではない**: チップ板（`plate_chip2`）の 9 分割で代用しており、板の上辺の飾りが伸びて線が多く見える。「気圧計」の語で頼み直す案。
3. **小サイズのアイコンがつぶれる**: 48 px の絵を 12〜18 dot に縮めている。使用先と表示サイズは下表。天候 7 種（18）と状態異常 3 種（12）は、その大きさで区別できる必要がある。
4. **未使用のアイコン**: 雷・盾・×・✓ は画面コードのどこからも呼んでいない。
5. **frame_thin（細い枠）は使えなかった**: 戦闘 HUD の 3 枠は `frame_gray` で代用。
6. **気圧メーター（6 コマ）と予報「NEXT ???」は見本**: 天候の現在値だけ実値に接続。予報の精度（#7）は未接続。
