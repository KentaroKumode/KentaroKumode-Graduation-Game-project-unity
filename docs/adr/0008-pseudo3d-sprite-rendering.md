# ADR-0008 — 疑似3D スプライト描画のゾーン別規約

## Status

Accepted（方針決定。戦闘盤 UI＝配線システム実装の前提）

## Context

戦闘へのプレイヤー介入（ダイス配線システム構想）に伴い、盤面 UI を今後何度も改修する見込み。
3D モデルの再配置・新造は改修コストが大きいため、**2D スプライトの配置換えだけで UI を
変更できる構造**にしたい。

前提の整理:

- **ピクセルパーフェクト（1px = 1dot = 物理4×4px）は LCD 上のみの制約**。
  ワールド側（ゲーム盤・筐体・部屋）は透視カメラで描画されており、そもそも画面上の
  ピクセル密度は距離で連続変化する＝厳密な 1:1 対応は最初から成立していない。
- LED ダイスはワールド側のゲーム盤上に存在する（LCD 内ではない）。
- 既存の LCD コンテンツ（タイトル/職業選択）は「ゾーンカメラ → RT → LCD Quad 転写」の
  平行投影レイヤード 2D。

## Decision

描画ゾーンごとに投影方式と制約を分ける。

### A. LCD コンテンツゾーン（contentCamera → RT）

- **平行投影のみ**。透視投影は持ち込まない（低解像度 RT に透視を流すとドットが暴れるため）。
- ピクセルパーフェクト厳守: PPU=8、X/Y は dot グリッドにスナップ、スプライトの 3D 回転禁止。
- レイヤーの **Z は実距離として使ってよい**（平行投影では見た目に影響しないため自由。
  重なりの自動解決・カメラドリーによる視差演出に利用可）。sortingOrder 併用可。
- 奥行きの「見た目」（パース・窪み・影）は実行時投影ではなく**素材に描き込む**。

### B. ワールドゾーン（ゲーム盤・筐体まわり、透視 worldCamera）

- **2D スプライトを 3D 空間に直接配置してよい**（疑似3D）。盤上の配線パターン・
  スロット端子・インジケータ等は、3D モデルではなくスプライト（Quad 貼り付け or
  SpriteRenderer）で構築する。
- 透視によるスケール変化・非整数サンプリングは**許容**（ワールド側に 1px=1dot 制約はない）。
- 配置形態は「盤面に寝かせる（デカール的）」「カメラ正対ビルボード」のどちらも可。
  ただしカメラアングルが浅い（グレージング）状態で寝かせスプライトが潰れる構図は避ける。
- テクスチャは Point フィルタ・PPU はゾーン内で統一（盤上 UI は PPU=8 を踏襲）。

### 共通

- `localScale` を状態表現に使わない規約（CLAUDE.md）は両ゾーンで継続。
  強調・選択は色/明度/差し替えスプライト/位置オフセットで表現する。
- 素材制作規約: 光源方向を全素材で統一（描き込み陰影の整合のため）。

## Consequences

- UI 改修＝「スプライト差し替え + Transform + （LCD側は dot 座標）」で完結し、
  3D モデリング工程が発生しない。
- 戦闘盤の配線 UI（スロット端子・信号の光走り）はワールド側スプライトとして、
  既存の LED ダイス表示と同じ空間に同居できる。
- LCD の絵はドット厳密、ワールドの絵は透視で歪む——質感の差は「筐体とその画面」という
  ダイエジェティックな関係性そのものなので、演出上の矛盾にはならない。
- **画中画の原則**（2026-07-13 確定）: ゲーム世界はゲーム盤内チップの演算結果にすぎない。
  **LCD の外（筐体・机・充電などの盤上機構）に lore は一切関与せず、lore 側も筐体に言及しない**。
  盤上機構のフレーバーはメカ用語で書き、世界観固有名詞（ヴェイランド等）を使わない。
- 情報表示（インテント・ダメージプレビュー等）は LCD 側、physical な操作対象
  （ダイス・端子）はワールド側、という役割分担を維持する。

## 描画ゾーン別インベントリ（2026-07-13 棚卸し）

判定基準: **「読む情報」は LCD、「触る/実在する装置」はワールド**。

### LCD コンテンツ（ゾーンカメラ → RT → LCD Quad、平行投影・dot 厳守）

|---|---|---|

| マップ（3レーン分岐ボード） | 実装済 (X=1500) | |
| 戦闘画面（駒・鍔迫り合い演出） | 実装済 (X=2000) | BattleVisualRig は contentCamera 視界内 |

| 要素 | 現状 | 備考 |

| ダイス合計モニター | 実装済 | DiceMonitorDisplay（自発光 Plane） |
| インベントリグリッド（盤上セル） | 実装済 | Cell 群はワールド Collider |
| **スロット端子**（武器/防御/パッシブの入力端子スプライト） | **新規** | 盤面に配置。疑似3D スプライト |
| **配線パターン**（端子までの配線絵 + 信号光走り演出） | **新規** | 永続配線の可視化 |
| **端子ハイライト**（選択可能/接続中の明度変化） | **新規** | localScale 不使用 |
| 3D 敵への着弾演出（勝利時） | 方針あり・未実装 | ワールド側かリグ内か**要決定** |

### 判断に迷ったら

- 数値・テキスト・一覧・プレビュー → LCD（ドットフォントの可読性が担保される）
- クリック対象で「機械の部品」として実在してほしいもの → ワールド
- 両側にまたがる表現（例: 端子クリック → LCD にプレビュー反映）は、入力=ワールド/出力=LCD に分割する

## 残タスク

1. **Codex / SkillTree の描画経路の棚卸し** — LCD ゾーン経由か確認し、上表を確定させる
2. **sortingOrder 帯域表の策定**（LCD 側）— 戦闘画面 + 新規インテント/プレビューを含む帯域を定数化（Ids.cs と同思想の定数ファイル）
3. **素材制作規約の文書化** — PPU=8・光源方向統一・パース角（描き込み奥行きの角度）を docs へ
4. **スロット端子・配線スプライトの盤面レイアウト設計** — LED ダイス・インベントリグリッドとの盤上同居配置。extraDice 系（最大5+追加）の渋滞対策（スロット数上限 + 未配置は攻撃へ自動合流）
5. **配線システムのデータ設計** — スロット定義の持ち主（職業ベース + 武器 + パッシブ拡張）、永続配線の保存先（RunState）
6. **敵インテント表示の情報設計** — 何をどこまで見せるか（スタンス/断罪周期/パッシブ発火予告）
7. **3D 敵着弾演出の帰属決定** — ワールド側 3D か BattleVisualRig 内か
8. **AutoRunner 事前計測** — 現行ビルド群の戦闘ターン数分布と「介入が意味を持つターン」頻度の計測（配線 UI のテンポ検証材料）

### 残タスク詳細（ワールド側・実装単位）

W1〜W3 が基盤、W4〜W6 で操作が成立、W7〜W8 で戦闘接続、W9〜W10 は演出。
（全体タスク #4 と #7 の詳細化。着手順もこの番号順を想定）

- **W1. 盤面レイアウト設計** — 詳細は下記「W1 詳細」。
- **W2. スロット端子の実体化** — 端子スプライト（攻撃/防御/パッシブ拡張の種別絵）＋
  BoxCollider。Point フィルタ・PPU=8。パッシブ由来端子は装備構成から動的生成。
- **W3. 配線パターン描画** — 盤面の配線絵（静的スプライト）。ダイス列→各端子の経路を
  持ち、接続状態で表示/消灯を切替。
- **W4. 状態ハイライト** — ダイス/端子の「通常/選択中/接続可/接続済/ロック（神経錯乱等）」
  を色・明度・差し替えスプライトで表現（localScale 禁止）。
- **W5. 盤面ポインタ入力（BoardPointer 新設）** — worldCamera レイ → ダイス/端子
  Collider 解決。LcdPointer と同型だが対象がワールド Collider。LCD Quad・インベントリ
  Cell と当たり判定が共存するため **RaycastAll + 対象フィルタ**パターンを踏襲。
  操作は 2 クリック（ダイス選択 → 端子選択）、ドラッグ不要。
- **W6. LED ダイスの選択対応** — SingleDiceLED（または親）に Collider 追加、
  選択中の点滅表示。DiceLEDManager に選択/消灯/転送の API を追加。
- **W7. 配線状態の永続化と戦闘接続** — 配線マップ（ダイス index → スロット id）を
  保持し（戦闘中は CombatContext、ラン跨ぎ既定値は RunState）、ターン開始時に
  前ターン配線を自動適用。**戦闘側のダメージパイプラインは
  [ADR-0009（相互攻撃モデル）](0009-mutual-attack-combat.md) を実装する**
  （2026-07-13 決定: 勝負判定への接続案は棄却。ロール比較はトリガー層として存続）。
- **W8. 転送演出** — ダイス消灯 → 配線上を光が走る → 端子点灯（出目表示）。
  0.15〜0.2 秒・スキップ可。**同配線の連続ターンは演出省略**（テンポ規約）。
- **W9. 3D 敵着弾演出** — 帰属決定（ワールド側 3D か BattleVisualRig 内か）→ 実装。
  配線システムとは独立に進められる。
- **W10. 素材制作** — 端子絵・配線絵・盤面マット絵。光源方向統一・パース描き込み規約
  （全体タスク #3 の規約策定後に着手）。

### W1 詳細 — 盤面レイアウト設計（2026-07-13 棚卸し込み）

前提の発見: **HP・空腹度・希望・ターン数の本番表示は未実装**（現状 `GameDebugHUD` の
IMGUI のみ＝差し替え前提の仮 UI）。GOLD は物理コイン（CoinSystem: ディスペンサー/
スタック/チケット変換）として盤上に実在済み。よって W1 は「配線盤の置き場所探し」では
なく、**机上全体の区画整理 + 計器類の新居決定**を含む。

#### W1-a. 机上の区画割り（ゾーニング）

盤上に載る全要素を区画に割り、worldCamera のフレーミング内で干渉なく同居させる:

| 区画 | 収容要素 | 現状 |
|---|---|---|
| LCD 区画 | LCD Quad（フェーズ画面・インテント・プレビュー） | 既存 |
| ダイス卓 | LED ダイス列（自5/敵5）＋ダイス合計モニター | 既存 |
| 配線盤 | スロット端子列＋配線パターン＋信号演出 | **新規** |
| 計器盤 | HP/空腹/希望/ターン数の常設計器 | **新規（本番UI未実装）** |
| 経済区画 | コイン皿/ディスペンサー/スタック/チケット | 既存（物理コイン） |
| 収納区画 | インベントリグリッド＋アイテムプレビュー(3Dテキスト)＋ツールチップ | 既存 |

#### W1-b. 計器盤の新設（HP/空腹/希望/ターン）

- 帰属判断: 数値情報だが「常時視界に必要・フェーズ非依存」なので **LCD 内ではなく
  盤上の物理計器**とする（LCD はフェーズごとに画面が切り替わるため常設に不向き）。
- 表現候補: LED バー（DiceLED の描画資産流用）/ セグメント数字（DiceMonitorDisplay
  流用）。HP=バー+数字、空腹/希望=バー、ターン=数字、が最小構成。
- **充電ゲージ**（ADR-0009 柱5）: 10 目盛り LED バー + 次ターン消費予定分の目盛りが**点滅**。
  エスカレーションゲージ（ターン数字 + 閾値ランプ）と並置。
- 希望は状態名（絶望/悲観…）の段階表示も検討（バー+状態ランプ）。
- `GameDebugHUD` は計器盤稼働後も開発用に残す（外すだけで消える設計は維持）。

#### W1-c. 配線盤の枠数と形状

- スロット枠数 = 職業別ベース（例: 攻撃/防御/固有の 2〜4 枠）+ パッシブ拡張枠。
  **物理レイアウト上の最大枠数を先に決める**（絵の描き直しを避けるため上限固定・
  未開放枠は蓋絵で塞ぐ方式を推奨）。
- ダイス側は自ダイス最大 5 + extraDice 系の一時増分。増分は LED 実体を増やさず
  「6 個目以降は自動合流（配線対象外）」とし、盤上は 5 系統の配線で固定。
- 未配置ダイスの自動合流先（攻撃端子）を配線絵で明示（デフォルト経路が視覚的に
  分かるように太線/常灯で描く）。

#### W1-d. 視線動線の設計

戦闘 1 ターンの視線が「LCD（インテント確認）→ ダイス卓（出目）→ 配線盤（采配）→
LCD（プレビュー確認・確定）」の N 字/Z 字で流れるよう区画を配置する。
計器盤は動線の中間（ダイス卓と LCD の間）が望ましい。

#### W1-e. カメラフレーミングとの整合

- 戦闘中の worldCamera 画角に「LCD + ダイス卓 + 配線盤 + 計器盤」が同時に収まること。
  経済区画・収納区画は戦闘中フレーム外でも可（フェーズでカメラが寄る運用は既存踏襲）。
- TitleCameraSway 系のカメラ揺れがある場合、配線盤の端子クリック精度に影響しないか検証。

#### W1-f. 干渉チェックリスト

- Collider 共存: LCD Quad / インベントリ Cell / 新設ダイス・端子 Collider が
  レイキャストで衝突しない配置 or レイヤー分離（LcdPointer の RaycastAll 問題の再発防止。
  **新設 Collider は専用レイヤーを最初に切る**）。
- コイン物理: 物理コインが配線盤・ダイス卓へ転がり込まない縁/高さの確保。
- 3D テキスト（アイテムプレビュー）と配線盤の重なり: 表示タイミングが排他か確認。

机上配置図 1 枚（区画・座標・カメラ画角・レイヤー割当を記載）。以降の W2〜W8・
素材制作（W10）はこの図を正とする。
