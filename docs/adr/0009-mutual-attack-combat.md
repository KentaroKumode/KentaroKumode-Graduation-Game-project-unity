# ADR-0009 — 相互攻撃モデル + ダイス配線 + 段階エスカレーション

## Status

Accepted（2026-07-15 ヘッドレス事前シミュレート通過 ── 下記「Verification 結果」参照。
実装は ADR-0008 の W7〈戦闘接続〉が本 ADR のパイプラインを実装する形で行い、
実装後に AutoRunner 実測（会心・実パッシブ込み）で数値を最終確認する）

## Context

プレイスキルの介入余地を増やす議論の到達点。検討の経緯（重要 — 各案の棄却理由が制約になる）:

1. **ダイス配線システム**（出目をスロット端子へ割り当て）を介入手段として採択（ADR-0008）。
2. 勝負判定（合計比較）の上に配線を載せる案は、以下の構造欠陥が連鎖的に見つかり棄却:
   - 敵合計が見えた後の配置は「必要攻撃量の逆算 + 余り流し」の算数に退化する
   - 敗北ダメが `max(|差|, threat)` である限り、攻撃ダイスは「勝率+勝ちダメ+負け差の圧縮」の
     三役を兼ね、同レートの防御端子は**完全に支配される**
   - 敗北ダメを差から分離しても、削り切らないと勝てないゲームで「盤面を進めない純軽減」は
     ジリ貧の罠択のまま（攻撃は戦闘短縮で総被弾も減らすため）
3. 相互攻撃モデル（勝負判定でダメージを決めず、両者が毎ターン攻撃する）は
   「早期決着に賭けるか、安全な長期戦を組むか」のジレンマを構造が素で生成する。
   完全情報でも成立する（被弾を"効率よく受ける"レース判断が熟練の中身になる）。
4. 残課題「ブロック合戦の膠着（長期戦が無限に安全）」は**段階エスカレーション**
   （敵攻撃値が T5/10/15/20 でスケール）が時計として解決する。

## Decision

### 柱1 — ダイス配線（介入手段）

自分のロール後、出目を端子へ割り当てる（ワールド盤上の配線盤 = ADR-0008 W2〜W6）。

| 端子 | 効果 |
|---|---|
| 攻撃 | 置いた**出目**分、自攻撃ダメージへ加算（高い目の定席） |
| ブロック | 置いた**出目**分、敵攻撃を軽減（毎ターン敵攻撃が必ず来るため無駄にならない） |
| 充電 | 置いた**ダイス個数**分（出目不問）「充電」を獲得 → 柱5。屑目の定席 |
| 特殊 | **ショップで購入した特殊端子を 1 つ装着**（下表・2026-07-14 確定）。未購入時は蓋絵 |
| （蓋） | 予備枠。物理最大 5 枠固定（ADR-0008 W1-c） |

- **配線は残る**: 前ターンの配線を自動適用。未配置は攻撃へ自動合流。介入は例外時のみ（テンポ規約）。
- 振り直し(#1)は存続。振り直し後も配線先は変更不可（事後情報での再配置を防ぐ）。

#### 特殊端子（2026-07-14 確定・ショップ商品）

**[接続制限 N]** = その端子に同時接続できるダイス数の上限。パワー上限と枠圧を一語で制御する
中核パラメータで、レアリティと連動させる（Ⅰ=B〜S / Ⅱ=G / Ⅲ=L 目安）。

| 端子 | 制限 | 効果 |
|---|---|---|
| 重攻撃 | Ⅰ | 接続ダイスの出目を **1.5 倍**して加算 |
| 完全防御 | Ⅰ | 接続ダイスの防御値（ブロック相当）を **2 倍** |
| 出血 | Ⅱ | 接続合計値分の出血を敵に付与し、接続**ダイス数**分だけ出血を発動させる |
| 治癒 | Ⅰ | 接続合計値分 HP 回復（制限Ⅰにより最大 6/ターン ── 回復一択化を上限で殺す） |
| 決死 | Ⅲ | 接続合計値分の自傷 + 同数を加算し、さらに**不足 HP の 5%** を加算 |
| 急所 | Ⅰ | 接続ダイスが**そのロールの最小値**の時のみ発動: 軽減不能ダメ + 出目×2 |
| 照準 | Ⅰ | 接続出目 ÷2（切上げ）を会心分子に加算（そのターンのみ） |
| 蓄電池 | Ⅱ | 充電獲得が 1 ダイスあたり +2（充電端子の倍率強化） |
| 冷却材 | Ⅲ | 接続合計値を蓄積、閾値到達でエスカレーション段階を 1 ターン遅延（1 戦闘 N 回まで） |
| 鋳造口 | Ⅰ | 接続合計値を蓄積、**N に達するたびにこの戦闘中のダイス合計値 +1**（恒常変換） |
| 反攻 | Ⅱ | このターン受けた最終ダメージのうち、接続合計値までを敵へ反射 |

- 「加算」（重攻撃/決死/鋳造口）の行き先は**攻撃ダメージ**（2026-07-14 確定 ──
  ロール勝負の完全廃止〈柱2〉により比較層が消滅、曖昧さ自体が解消）。
- 数値（倍率・N・閾値・価格）は全て暫定。AutoRunner スイープ対象。

#### レイヤリング原則（2026-07-14 確定）

「何がどこでロジックを持つか」を 3 層に固定する。旧モデルの「パッシブがロール合計を
書き換える」習慣は持ち込まない。

| 層 | 役割 | ロジック |
|---|---|---|
| ダイス（装備） | 素材の物理特性のみ: 振る個数・面数 (d4/d6/d8…) | **持たない** |
| 端子 | 出目の変換先（能動・配線が要る） | 変換ルール |
| パッシブ | 常時装置（電力が要る・柱5） | 解決時の修飾チェーンで発動 |

- **ダイス側パッシブは廃止**。ダイス装備の個性は物理差（振れる個数・面数）で表現する
  （配線の原資が変わる = 新モデルでは物理差だけで十分な個性になる）。
- 既存ダイス固有パッシブの転生先:

| 旧ダイス固有 | 処遇 |
|---|---|
| 完全（重複あり→強化） / 星導（全相異） / 運命（全最大/最小） / 星命（ゾロ目） | パッシブアイテムへ転生（最終出目のパターンを読むだけ ── 機能無傷・置き場所の変更のみ） |
| 永劫（勝利で蓄積・ラン跨ぎ） | パッシブへ転生。「勝利」参照は収支プラスへ読み替え |
| 貪欲（吸血） / 諸刃（負傷） | パッシブへ転生 or 廃止（ダイスに紐づく必然がない） |

- **見えない補正の禁止**: パッシブはロール値（LED の表示）を直接書き換えない。効果は
  解決時の修飾チェーン（与ダメ/被ダメ/回復 等）でのみ発動する。
  例外は「**出目操作**」カテゴリ（記憶の砂時計の最低値→最大化 等）のみで、これは
  **LED の表示が実際に変わる**形でのみ許可 ── 「LED に見えている出目 = 配線に使える値」を
  常に真にし、収支プレビュー（柱3）の信頼性を保証する。
- ターン構造 step 3 の「自パッシブ集計」は出目をいじる工程ではなく、解決時に発動する
  装置の armed 状態を整える工程。敵側の号令/ランプ系は攻撃値（ダメージ側）への加算であり
  本原則と矛盾しない。

#### 棄却・改廃の記録

- 2026-07-13: 第三端子の単機能候補 10 案は充電端子への統一で棄却。パッシブ差し替え式の「拡張端子」廃止。
  「ソケット複数化 + チップ換装・販売」案も棄却。
- 2026-07-14: **職業固有端子（剣士=追撃/騎士=聖盾/狂戦士=血の代償/暗殺者=急所）を廃止**
  （やりすぎ ── 職業差は class-system.md の「スターター消耗品 1 個」原則に回帰。同 spec との矛盾も解消）。
  跡地に**特殊端子**を新設: チップ案のうち「端子の中身をショップで販売する」部分だけを
  1 枠限定で復活させた形（ソケット複数化はしない）。旧固有効果の一部は特殊端子プールに転生
  （聖盾→完全防御 / 血の代償→決死 / 急所→急所）。整流器（次ターンの出目固定）は不採用。

### 柱2 — 相互攻撃モデル（ロール勝負の完全廃止・2026-07-14 改）

毎ターン、プレイヤー攻撃 → 敵攻撃の順で両者の攻撃が解決する。
**ロール勝負（合計比較による勝敗判定）は完全廃止** ── 当初はトリガー層として比較を残す案
だったが、①ダメージに影響しない「勝敗」表示は認知的不協和のノイズ ②相互攻撃では
「攻撃が通る」と「被弾する」が毎ターン併存し「勝ち XOR 負け」の意味論が元々壊れている、
の 2 点により廃止に変更（2026-07-14）。

```
自攻撃 = 武器素火力(attackPower) + 攻撃端子の出目合計 (+特殊端子) → 既存の与ダメ修飾チェーンへ
敵攻撃 = 敵基礎攻撃値(enemies.json 新パラメータ・段階スケール後) + 敵ダイスロール合計
        − ブロック端子の出目合計 (下限0) → 既存の被ダメ修飾チェーンへ
```

- **敵ダイスは「敵攻撃値の振れ」として存続**: LED 演出・振る本数のテレグラフ・
  スタンス（強振り/弱振り）はそのまま意味を持つ。**敵はプレイヤーより先に振り、実値を予告する**
  （下記ターン構造）── ブロック量の判断は分布への賭けではなく**実値への応手**
  （わざと受けてレースする判断が熟練の中身）。
  号令/業火の遺志などの敵ダイス加算パッシブは攻撃値ランプとしてほぼ無改修で移行。
- **トリガー層は「収支」に置換**: 収支 = そのターンの与ダメ − 被ダメ。
  `OnRollWin` → **収支プラスのターン** / `OnRollLose` → **収支マイナスのターン** に再定義
  （排他性が保たれるため、復讐・業の連鎖・重畳などの意味構造がそのまま移る。
  収支はレースの進捗そのもの＝痕跡ではなく本物の指標）。
- **完全廃止**: `diceDifference`・差依存ダメージ（断罪の天秤・天命の倍率条件 等十数個）・
  引き分け再ロール・画竜点睛の即勝利上書き・敗北 base の threat 床・
  スタンス 2 本（ADR-0005/0006。敵スタンスは攻撃値の高低テレグラフとして再利用）。
- **UI**: 勝敗表示 → 収支表示（そのターンの交換結果 +7 / −3 等）へ置換。
- ゾロ目/階段/全相異など出目参照パッシブ、希望リロールは存続
  （リロール自動ポリシーの目的関数は「勝率」→「配線価値」へ変更）。

#### ターン構造（2026-07-14 確定・8 段）

```
0. ターン開始処理  : 充電消費判定 (柱5・通電/停電の確定・ゲージ更新)、DoT/ステータス tick
1. 敵ロール        : 敵ダイス発火 + 敵パッシブ集計 → 敵攻撃合計 確定
2. 予告            : LCD に敵攻撃値・スケール段階・次段階までの残ターンを表示
3. 自ロール        : 自ダイス発火 + 自パッシブ集計
4. リロール (任意) : 希望を払って振り直し ── 配線前のみ可
5. 配線            : 前ターン配線が自動適用済み・変更はここ → LCD に収支プレビュー
6. 解決            : プレイヤー攻撃 → 敵攻撃 (敵 HP 0 で即終了・敵攻撃は発生しない)
7. ターン終了処理  : OnTurnEnd 系 → 1 へループ
```

- 充電消費 (0) が敵予告 (2) より前なのは意図的 ── 停電の有無が確定しないと配線判断 (5) の
  収支計算が立たないため。
- 旧ルール「振り直し後も配線先は変更不可」は**廃止** (2026-07-14)。あれは事後情報での
  再配置を防ぐ規則だったが、本フローでは配線時点で敵実値も自分の出目も見えているのが
  正規状態であり、防ぐべき事後情報が存在しない。
- 6 の解決順 (プレイヤー先制・撃破時は敵攻撃なし) は全戦闘の体感難度を決める急所。
  変更する場合は AutoRunner 再計測が必須。

### 柱3 — 完全情報テレグラフ

敵の攻撃値・スケール段階・次段階までの残ターンを盤上/LCD で公開する。
隠すことで守っていた均衡（情報切断）は不要になったため、読める情報は全部見せる。

### 柱4 — 段階エスカレーション（時計）

- 敵攻撃値が **T5/10/15/20 の可視閾値**で段階スケールする。
  ラッシュ=HP（ラン通貨）で前払い / グラインド=スケールで後払い、の賭けを作る。
- スケール対象は**攻撃値のみ**（HP/防御をスケールさせると長期戦だけが一方的に壊れる）。
- **敵ごとのプロファイル**を enemies.json で描き分ける:
  急スケール型（ラッシュ教師）/ 緩スケール型（グラインド許容）/ スパイク型（特定 T のみ危険）。
- 狂暴化（T50）は最終段階として体系に統合。断罪周期はスパイク型の先行例。
- 計器盤（ADR-0008 W1-b）に**エスカレーションゲージ**（ターン数字 + 閾値ランプ）を常設。
- チューニング目安: シールド蓄積系のグラインドビルドが**第 2〜3 閾値までに損益分岐**する傾斜。
  きつすぎるとラッシュ一強の逆極化が起きる。

### 柱5 — パッシブ電力経済（充電端子）

パッシブを「電源を要する装置」にする。持っているだけで働く無料の複利をやめ、
パッシブ枚数そのものをビルドの賭けにする。**数値仕様はモチーフ確定後に詰める（以下は暫定）**。

- 充電端子に置いた**ダイス個数**分の充電を獲得（出目不問・最大 10 ゲージ）。
- ターン開始時に `1 + (発動可能パッシブ N 個ごとに +1)` を消費し、そのターンの全パッシブを有効化。
- 消費できる充電が不足（消費予定量に未達）の場合、そのターンはパッシブを発動させない。
- 実装フック: パッシブ一時停止は既存機構（迷妄の `DisableRandomPlayerSkills` /
  静寂のローブの敵パッシブ封印 / 寂照）と同系統の配管を流用できる。
- 計器盤（ADR-0008 W1-b）に充電ゲージ（10 目盛り LED バー）を常設。

決定事項（2026-07-13 Q&A で確定）:

1. **停電は全停止**（部分給電なし）。呪い・デメリット系パッシブも止まる。
   「わざと停電してデバフを消す」は成立するが、パッシブはメリット側が圧倒的多数のため
   自殺ビルド級の例外を除き停電は常にデメリット ── ニッチな抜け道として許容する。
2. **課税範囲は全パッシブ系統**（汎用/固有・パッシブアイテム・武器/ダイス付随）。
   ただし**デバフ（契約デメリット・Λ・メタデバフ等のマイナス効果）は消費数 N に数えない**
   （呪いを抱えても電気代は上がらない。停電時に止まるのは 1. のとおり）。
3. **停止は戦闘中トリガーのみ**。OnMapMove / CombatEnd 系は電源外（免税）。
   評価軸は「戦闘に勝てるか」に一本化する。
4. **消費量はターン開始時の通電対象所持数で確定**（そのターンの実発火数ではない）。
   毎ターン開始時に再計算するため、寂照のパッシブ喪失・迷妄の無効化など
   戦闘中の枚数変動があっても自動で追従する。
5. **消費予測はゲージの点滅表示**（消費予定分の目盛りが点滅）。計器盤の充電ゲージ仕様に含める。

残る数値の宿題（モチーフ確定後）: N（何個ごとに +1）・最大ゲージ・初期充電
（満タン/固定値/戦闘跨ぎ持ち越し）・エスカレーションとの複利圧の傾斜 ── いずれも
Verification 5. のスイープで当てる。

## Verification（Accepted 判定の条件・AutoRunner）

実装前にヘッドレスで新旧パイプラインを比較シミュレートする:

1. **ターン数分布** — 相互攻撃 + エスカレーションで戦闘が間延び/短絡しないか（現行分布と比較）
2. **膠着検出** — ブロック合戦で敵 HP が減らないターンの連続数
3. **スケール傾斜スイープ** — 傾斜 × ビルド別（アグロ/バランス/ガード/シールド蓄積）勝率と
   HP 収支。グラインドの生存権とラッシュ一強化の両側をチェック
4. **配線分散** — 配置ポリシーの端子分散（攻撃一極なら端子レート再調整）
5. **電力経済**（柱5） — 無パッシブ・ラッシュが暗黙の最適解にならないか /
   パッシブ枚数 × 充電投資量ごとの勝率マトリクス / ブラックアウト頻度

## Verification 結果（2026-07-15 ヘッドレスシミュレート）

シミュレータ: [tools/adr0009_sim.py](../../tools/adr0009_sim.py)（8 段ターン構造・完全情報配線
3^5 全列挙・実 enemies.json 入力・BOT 緊急回復近似あり / 会心・実パッシブ・敵パッシブは抽象化）。
レポート: `AutoRunLogs/adr0009_sim/sim_report.txt`。
旧基準: batch_20260623 n10000（ボス平均 2.1〜23.9T）。

| 条件 | 判定 | 所見（推奨点 alpha=1.0 / HP×0.5 / β=0.3） |
|---|---|---|
| 1. ターン数分布 | 合格 | ボス帯 6〜13T（旧 6〜24T）。間延びなし。雑魚/エリートは 1〜2T と短絡気味 → HP 個別再調整で吸収（下記） |
| 2. 膠着検出 | 合格 | 全設定・全ビルドで最大膠着 0 ターン。相互攻撃は構造的に膠着しない |
| 3. 傾斜スイープ | 合格 | 傾斜 mid でアグロ 87% / バランス 76% / ガード 74% / シールド蓄積 95%（損耗 1.2HP=無償でない）。rush はガードを、gentle はグラインド課金を壊す |
| 4. 配線分散 | 合格 | 攻撃 62〜75% / ブロック 14〜17% / 充電 10〜23%（攻撃系）。ガード系は反転。単極化なし |
| 5. 電力経済 | 合格 | 無パッシブ 65% < P2〜6 で 81〜85%（N=3・初期充電5）。「無パッシブ・ラッシュ最適」は否定。停電 0.7〜3 回/戦 |

**シミュレートで確定した構造知見（実装時の必須制約）**:

1. **敵ダイスの攻撃寄与は圧縮必須（β≈0.3）** ── 旧ロール勝負用ダイス（4d8 等）を攻撃値へ
   直に加算するとレースが構造的に閉じない（毎ターン 18 点級の圧で 5T 決着・エスカレーション不発）。
   enemies.json 新パラメータは「基礎攻撃値 + ダイス寄与率」の 2 本で持つ。
2. **エスカレーション倍率は敵攻撃値全体（基礎+ダイス寄与）に適用** ── 基礎のみだと
   シールド蓄積系の成長 (+9/T 級) を追い越せずグラインド無敵化する。
3. **敵 HP はグローバル ×0.5 目安で再スケール** ── 旧 HP はロール勝負前提の値。
   雑魚/エリート帯は 1T 撃破の短絡が出るため個別に上げ直す（Phase 6 の再収束で確定）。
4. **推奨初期値**: 既定傾斜 = mid `[1.00, 1.30, 1.60, 1.95, 2.30]` / 充電 N=3・最大 10・
   戦闘開始時 5（半充電）。N=4 は高パッシブ数で電気代がほぼ無料化するため不採用。

## Consequences

- `DAMAGE_CALC_REFERENCE.md` は §1 パイプラインを全面改訂（実装と同時・規約どおり）。
- enemies.json に攻撃値 + エスカレーションプロファイルのパラメータを新設。
- 契約 12 旅団を含む既存バランスは再収束が必要（BOT オートラン)。
- ADR-0005/0006 は本 ADR の Accepted 時に superseded 予定。
- ボス群（覚者 7 形態・シュヴァリエ等）の固有機構は個別に移植判断（勝敗参照は収支トリガーへ読み替え、
  敵ダイス加算系は攻撃値ランプとしてほぼ無改修で移行できる見込み）。
