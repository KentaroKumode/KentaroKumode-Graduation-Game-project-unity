# ADR-0013 — 防御力と貫通

## Status

**Proposed（2026-10-28）。Unity へ実装済み・バランス測定は未。数値は全部仮置き。**

## Context

- プレイヤーに防御力は無く、被ダメを減らすのはブロック配線と、散らばった「被ダメ −N」（剣の〈間合〉、盾の〈城壁〉など）だけだった。
  〈城壁 III〉の −7 は 1〜2 層の敵（攻撃 3〜11）をほぼ無力化していた。
- 敵の防御は `baseDefenseRate`（被ダメ % 軽減）で、持つのは 5〜7 層のボス 7 体と精鋭の一部だけ。
  雑魚の硬さ（〈硬鱗〉〈重甲〉〈虚体〉〈霊体〉）はパッシブで、貫通の前に処理されるので貫通が効かなかった。
- その結果、「この敵のために貫通を用意する」という準備がゲームのどこにも無かった。
  余った貫通を与ダメ % に変える仕組みのせいで、貫通はただの与ダメ % の亜種になっていた。

防御力の価値は軽減そのものではなく、**無視・貫通・変換との相互作用**で出す。
HP は無視も貫通もされないので、防御は HP と別の軸になる。

## Decision

1. **防御値（整数）を両陣営に持たせ、同じ式で軽減率にする。** `R(D) = Rmax × D / (D + K)`。
   Rmax < 1 なので、積むほど実効 HP の伸びが落ちる（素の `D/(D+K)` は実効 HP で見ると線形で逓減しない）。
2. **プレイヤーの防御はブロックの前に掛ける。** 敵の攻撃値に掛け、予告の数字に反映する。
   ブロックに要る本数が減り、浮いたダイスを攻撃・充電に回せる ── 配線の判断は残る。
3. **プレイヤーの防御の出どころ**: 初期値 ＋ 武器 ＋ アイテム（ステータス `def`）。
4. **貫通は防御値を固定値で引く**（`max(0, D − 貫通)`）。両陣営とも同じ。
   敵がプレイヤーの防御を崩す手段も、この固定削り（敵データの `armorPen`）と既存の軽減無視。
5. **余剰貫通の与ダメ % への変換は撤去。** 貫通は装甲持ちにしか効かない。
6. **武器の家系を貫通〜防御の 1 本の線に並べる。** 短剣＝貫通最大・防御 0 ／ 斧＝貫通高・防御低 ／
   剣＝中・中 ／ 盾＝貫通 0・防御最大。段（T2→T4）と "+" で比率を保ったまま量が増える。
   交換レートは **防御 1 = 貫通 2**（貫通は装甲持ちにしか効かないので多めに配る）。〈竜閃〉は貫通 99・防御 0。
7. **既存の硬さの整理**: 〈硬鱗〉〈重甲〉と精鋭の基礎防御は防御値へ。〈虚体〉〈霊体〉は貫通の効かない別系統として残す
   （固定ダメージ・手数で答える）。
8. **武器スキルの被ダメ −N は外す**（〈間合〉〈城壁〉）。武器そのものの防御が肩代わりする。
   〈一対一〉の単体戦のみの被ダメ −N は、単体戦のみの防御 +N へ置き換える。
9. **（2026-10-28 追記）武器家系のラダーを、防御と貫通の使い方で分け直す。** 1 段に仕組みは 1 つ。

   | | 速い・確実 | 遅い・不確実 |
   |---|---|---|
   | 敵の防御を越える側 | 短剣: 初手から抜ける（〈急所〉会心は防御無視） | 斧: 殴るほど割る（〈鎧砕き〉）・守りは捨てる（〈血令〉防御→貫通） |
   | 自分の防御を使う側 | 剣: 剥がされない（〈間合〉敵の固定削りを打ち消す） | 盾: 最大だが剥がされる。受けて溜め（〈城壁〉〈堅守の構え〉）放つ（〈シールドバッシュ〉〈黎明〉） |

   - 配線を条件にする段（剣〈切り返し〉〈不滅の刃〉・盾〈シールドバッシュ〉〈堅守の構え〉）のために、
     配線確定直後のトリガー **`OnWired`** を足した（atkBase の確定より前）。
   - **しきい値型の条件を避ける。** 「敵の攻撃を完全に受け止めた次のターン」はボスの攻撃を受け切れず雑魚戦専用になる。
   - **防御を連打する構成を最強にしない。** 溜めているだけのターンは火力ゼロにし、放つのは全部攻撃のターンか無傷で受け切ったときだけ。
     「（ブロック＋防御で減らした量）× 係数」の反撃は、複雑なうえ防御連打が理論上最強になるので棄却した。
   - 削除・置換した段と理由は GAME.md §24、効果の式は DAMAGE_CALC_REFERENCE §3-B2、表は GAME.md §9-4b。

## Consequences

- 廃止: `EnemyData.baseDefenseRate`（→ `defense`）・`armorPenPct`（→ 貫通の点）・余剰貫通の与ダメ転用・
  〈硬鱗〉〈重甲〉の固定減算・〈間合〉〈城壁〉の被ダメ −N。
- **旧経路（`UseMutualAttackPipeline=false`）にはプレイヤーの防御を入れていない**（比較スイープ専用の退避経路のため）。
- 武器以外の「被ダメ −N」を持つパッシブ（〈戻り数なき革胸当て〉など）は**未整理**。硬くなりすぎる疑いがあり、別途検討する。
- 敵側の装甲持ち（2 層から少数・3 層で本格化、高防御低 HP／予告つきの構え／割れる装甲／積み上がる装甲）と、
  ボス・エリートの大きな固定削りは**エネミー再編で入れる**。それまでは防御を積んだ側への天敵が軽減無視だけになる。
- 現実的に積める防御値と各ボスの固定削りの突き合わせは、アイテムとエネミーの再編後に行う。
- 予告の数字は防御を引いた後の値になる。画面に防御値そのものを出す UI はまだ無い。
- （2026-10-28 追記）武器家系の整理で削除: 盾〈反攻〉〈パリィ〉〈衛士の慣い〉・剣〈果たし合い〉・斧〈復讐〉〈大鉈〉・
  短剣〈蝕夜〉と〈処刑〉のダイス潰し・品〈内から落ちた城盾〉と効果クラス ShieldBashI〜III。〈騎士団の切り札〉はリワーク。
- **BOT の配線方策は新しい段を知らない**（剣の分け方・盾の振り切り・〈堅守の構え〉の時期）。測定の前に方策を直さないと、
  家系の強さではなく方策の出来を測ることになる。
