# 実績システム仕様

更新日: 2026-08-12

## 1. 基本方針

- 実績は恒久的な戦闘性能を与えない。報酬を追加する場合は称号、図鑑、タイトル装飾に限定する。
- 解除状態はメタ進行データへ保存し、同じ実績を二重解除しない。
- AutoRunner、バランス測定、診断用ランでは解除しない。
- セルフ縛りは事前宣言を要求せず、ラン開始からの行動履歴で判定する。
- 複数条件を同時に満たした場合はすべて解除する。
- 隠し実績は解除前の名前と説明を `？？？` とする。
- GUIは本仕様の実装範囲外。実績一覧、解除照会、解除イベントをゲームロジック側から利用できるようにする。

## 2. 難易度クラス

挑戦ポイントから次のクラスを一意に算出する。クラスは表示用であり、追加のゲーム補正を持たない。

| 挑戦ポイント | 難易度クラス |
|---:|---|
| 0–9 | `STABLE` |
| 10–19 | `CAUTION` |
| 20–29 | `DANGER` |
| 30–39 | `CRITICAL-SITUATION` |
| 40–49 | `FATAL-ERROR` |
| 50 | `CATASTROPHIC-ERROR` |

## 3. 実績一覧

### 3.1 基本・到達（7）

| ID | 名前 | 条件 |
|---|---|---|
| `first_run` | 最初の一歩 | 初めてランを開始する |
| `boss_1` | 第一の門 | 1層ボスを撃破する |
| `reach_3` | 地上は遠く | 3層へ到達する |
| `boss_5` | 災厄の先へ | 5層ボスを撃破する |
| `reach_6` | 〈決意〉 | 6層へ突入する |
| `reach_7` | 〈真理〉 | 7層へ突入する |
| `clear_7` | 覚者 | 7層をクリアする |

### 3.2 戦闘・ビルド（6）

| ID | 名前 | 条件 |
|---|---|---|
| `combat_wins_100` | 百戦錬磨 | 累計100回、戦闘に勝利する |
| `first_role` | 型を知る | 初めて役を発動する |
| `all_roles` | 型を極める | 全種類の役を累計で発動する |
| `win_at_1_hp` | 紙一重 | HPがちょうど1の状態で戦闘に勝利する |
| `boss_no_hp_damage` | 傷一つなく | HPダメージを受けずにボスを撃破する。盾による防御は可 |
| `boss_one_turn` | 一擲 | 3層以降のボスを1ターンで撃破する |

### 3.3 挑戦ポイント（5）

すべて7層クリアを要求する。上位条件を満たした場合、未解除の下位実績も同時に解除する。

| ID | 名前 | 条件 |
|---|---|---|
| `challenge_10` | CLASS: CAUTION // COMPLETE | 挑戦ポイント10以上 |
| `challenge_20` | CLASS: DANGER // COMPLETE | 挑戦ポイント20以上 |
| `challenge_30` | CLASS: CRITICAL-SITUATION // COMPLETE | 挑戦ポイント30以上 |
| `challenge_40` | CLASS: FATAL-ERROR // COMPLETE | 挑戦ポイント40以上 |
| `challenge_50` | CLASS: CATASTROPHIC-ERROR // COMPLETE | 全挑戦有効の50ポイント |

### 3.4 カテゴリ別MAX（5）

対象カテゴリの全基礎軸を最高Tier、対応T4をON、ほかのカテゴリをすべてOFFにして7層をクリアする。

| ID | 名前 | 条件 |
|---|---|---|
| `category_a_max` | 成立 | 生存圧MAX + 破綻 |
| `category_b_max` | 鋼断ち | 敵強化MAX + 鋼の皮膚 |
| `category_c_max` | 運命への反証 | 戦闘妨害MAX + 凶運 |
| `category_d_max` | 金貨なんて必要ない | 経済MAX + 破産 |
| `category_e_max` | 上告 | 崩壊MAX + 最後の審判 |

### 3.5 セルフ縛り（5）

| ID | 名前 | 条件 |
|---|---|---|
| `no_consumable_boss_5` | 節約家 | 消耗品を一度も使用せず5層ボスを撃破する |
| `no_purchase_boss_6` | 清貧 | 店で一度も購入せず6層ボスを撃破する。売却は可 |
| `no_reroll_boss_6` | 運命を受け入れるもの | 戦闘・店を問わず再抽選を一度も行わず6層ボスを撃破する |
| `no_relic_consumable_clear_7` | 持たざる者 | 遺物を一度も装備せず、消耗品も使わず7層をクリアする |
| `no_flee_boss_5` | 猪突猛進 | プレイヤーが一度も戦闘から逃亡せず5層ボスを撃破する |

「遺物を一度も装備せず」は最終状態ではなく、ラン開始時からの装備履歴で判定する。強制効果による消耗品適用は使用に数えず、プレイヤーが所持品を消費した場合だけを数える。

### 3.6 経済・遺物（6）

| ID | 名前 | 条件 |
|---|---|---|
| `first_relic` | 小さなお守り | 初めて遺物を入手する |
| `relic_main_max` | 主役の器 | メインステータスが最大値の遺物を入手する |
| `relic_sub_max` | 極致の一片 | サブステータスのいずれかが最大値の遺物を入手する |
| `relic_all_max` | 完全無欠 | メイン・サブを含む全ステータスが最高値の遺物を入手する |
| `zero_gold_boss_6` | 空の財布、満ちた決意 | 所持金0の状態で6層ボスを撃破する |
| `cursed_relic_clear_7` | 呪われた至宝 | 呪われた遺物を装備した状態で7層をクリアする |

遺物の最大値は通常値を用いる。メインは段9、サブは段5。呪いによるメイン段10は「最大値以上」としてメイン最大条件を満たすが、全ステータス最高では段9を要求する。

### 3.7 物語・隠し（12）

| ID | 名前 | 条件 |
|---|---|---|
| `hidden_saint_georges` | 剣との対話 | 5層隠しボス「シュヴァリエ」を撃破する |
| `hidden_final_page` | 最後の頁 | 6層専用イベントで「最後の頁を開く」を選択する |
| `hidden_no_blaze_boss_6` | 灰は灰へ | 烈炎を一度も増加させず6層ボスを撃破する |
| `hidden_thirteenth_end` | 十三番目の終わり | ラン累積13戦闘ターン目に、ちょうど13ダメージで敵を撃破する |
| `hidden_theseus` | テセウスの船 | ラン開始時最大HPの1000%を超える累積HPダメージを受け、死亡せずランを完了する |
| `hidden_overkill` | やりすぎ | 残りHP1の敵に一撃で100以上のダメージを与えて倒す |
| `hidden_calm_down` | 落ち着けよ、兄弟 | HP1のまま回復せず3ターン以上生存し、その戦闘に勝利する |
| `hidden_perpetual_motion` | ノーベル賞は私のモノ | 1戦闘中に最大HPの300%以上を累積回復して勝利する。超過回復も計上する |
| `hidden_turn_124` | あと一ターンだけ | 最後の審判が発動する直前、累積124ターン目にボスを撃破する |
| `hidden_shop_stubborn` | しつこい交渉 | 1回の店で購入・売却・再抽選をそれぞれ3回以上行う |
| `hidden_exact_zero_purchase` | 買い物上手 | 1回の購入によって所持金をちょうど0にする |
| `hidden_returning_enemy` | 昨日の敵は今日も敵 | 同一ラン中に逃亡した敵と同種の敵へ再遭遇し、撃破する |

「累積HPダメージ」は盾で防いだ量を含めず、実際にHPから失われた量を数える。「ラン完了」は5・6・7層の正規エンディング到達を指し、死亡、放棄、タイトル帰還を含めない。

## 4. 永続化と公開API

- メタ進行データは解除済みID、解除UTC、累計戦闘勝利数、累計発動役ビットマスクを保持する。
- 実績サービスはカタログ一覧、解除済み照会、解除処理、解除イベントを公開する。
- ラン中の一時カウンタはセーブせず、ラン開始時に初期化する。
- 未知の実績IDがセーブに含まれていても削除せず、既知IDの照会だけを行う。
- 実績解除時にメタ進行セーブを即時保存する。
