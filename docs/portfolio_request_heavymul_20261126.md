# 依頼: 大技の倍率を上げると「読む価値」が開くか（2026-11-26）

`docs/portfolio_metrics_20261126.md` の続きです。結果は同じファイルに **「⑫」** として追記してください（①〜⑪ は書き換えない）。
**この依頼は測定だけです。** 数値・規則・BOT のコードは変えないでください（不具合を見つけたら止めて報告）。

## 目的

⑪ で、規則を知る熟練者（`S_T`）は知らない熟練者（`S_Tu`）より失う HP が有意に少なかったのに、3 層クリア率の差は +0.29 pp（p=0.07）にとどまりました。
作者の見立て: **今の大技は HP で払える程度（最大 HP の約 21%）で、止めても止めなくても勝敗が変わりにくい。だから読む価値が小さい。**
（⑩-1 でも、多くのボスで大技を 1 回受けた時の敗北率は 0 回の時とほぼ同じ）

そこで、**小技の倍率は触らずに、大技の倍率だけを 3 段上げて**、読む腕と読まない腕の差が開くかを測ります。
これは 2026-11-14 の作者の決定「周期 5 にしたうえで大技の火力を上げる（×3.0〜5.0 を測ってから決める）」の測定でもあります（GAME.md §13）。

**2026-11-26 追記: この依頼を書いた後で、2 つが既定になりました。** ⑪ とは条件が違うので、⑪ の結果は再利用できません。
- ダウンの規則が「割った瞬間に効く」形（`downCancelRule = Instant`・GAME.md §23-36）になった。大技のターンに通常攻撃で割ると、その場で大技が止まり、次のターンは大ダウン。小技のターンはそのターンの行動だけ止まる（よろめき）。チャージのターンは無効。
- BOT の帳簿の残りターン数の連続化（`v3.ledgerContinuous = True`）が既定になった（熟練者が +3.41 pp 前後強くなる見込み）。
- 大ダウンの受けるダメージの倍率が ×1.5 → **×2.0**（`BossDown.TakenMul`）。

## 入ったもの（2026-11-26）

  あちらはデータでなく定数（`BossParams.Depth3HeavyMul` = ×2.0・小技 ×0.6）で足しているので、今まで上書きできなかった。

## 判定の書き方（守ること）

- 差（`S − Su`）が段とともに有意に開く → 「大技の火力が、読む価値のつまみとして効く」。どの段で 3 層クリア率の差が有意になったかを書く
- 開かない → **「読む価値が無い」と断定しない**。「この BOT の見積もりの上では開かなかった」と条件付きで書き、大技の取り消しの差と、溜めで無効の数の差が段で変わったかを必ず添える（変わらないなら BOT が規則を使えていない可能性が高い）
- 難易度の変化は報告だけ。経験者を 40% に戻す小技・HP の調整案は書かない（作者が決める）
- 推測で原因を断定しない。数字が支える事と推測を分けて書く
