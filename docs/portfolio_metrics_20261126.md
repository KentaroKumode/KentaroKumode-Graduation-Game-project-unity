- **ポートフォリオ3ページ目への活用ポイント**: 「最終バランス計測（12月）で確かめる」を消し、**「各1万ラン×4腕の対比較で検証 → ダウンありでも2ターン先読みの上乗せは -0.10 pp（p=0.71）・交互作用 -0.01 pp（p=0.97）で仮説は外れと判明」**と正直な検証結果として完結させる方が、データ駆動設計の説得力が高い。

## ⑧ ⑦の原因分析と改善案（ダウンの段取りで勝率差を出すための検討）

⑦の 10,000 ラン対比較で `Aim1 − Aim0` に有意差が出なかった（3層クリア `-0.09 pp`, `p=0.467`）背景について、計装と `BossDown.cs` / `AutoRunner.Terminals.cs` の構造から整理した原因と改善案。

### 原因分析（計装と現行ルールの構造）

1. **「雑に割っても半分以上当たる」構造**
   - 現行 `DownCancelRule.ChargeOrHeavy` は、3〜4ターン周期のうち「チャージ」と「大技」の **2ターン両方** を取り消し対象にしている。
   - そのため、一切狙わない `Aim0` でも、大技持ち戦のダウンのうち過半数（取り消し `27,820` 回 vs 空振り `23,624` 回）が偶然チャージか大技に重なって消えている。
2. **「狙って合わせた見返り」と「雑に割った見返り」の差が小さい**
   - 小技ターンに即割っても「被ダメ ×1.5 ＋ 1T行動不能」が得られ、大技に合わせて割ってもダウンの性能は同じ ×1.5 のまま（違いは大技周期のリセットのみ）。
   - ボスを 7〜10 ターンで倒し切る現在のテンポでは、**1ターン攻撃を控えて待つ損失 ＞ 大技を1回遅らせる得** になりやすい。
3. **「待つ」判断の採用率と発生頻度自体が低い**
   - `ApplyDownAim` の割引係数 `downAimGainShare = 0.2` が強いため、比較判断 `14,380` 回のうち待つ手を選んだのは **18.39%（2,644回・全 64,461 ボス戦あたり 0.041 回/戦）** に留まった。
   - また、大技取り消しが `+719` 回（`27,820 → 28,539` 回）増えて大技を受けた回数が `-265` 回減っても、ボス戦平均失HPは `14.03% → 14.02%`（対差 `-0.03 pp`）しか動いていない。

### 改善案（優先度順・未実装）

- **案A（本命・ゲームルール側）：「大技／チャージへのカウンター割り」と「小技ターンの雑な割り」に明確な性能差をつける**
  1. **当たり枠を1ターンに絞る**: 取り消し＆強ダウンの対象を「大技のターン（またはチャージのターン）の1ターンだけ」に絞り、小技ターンの雑な割りは「ひるみ（被ダメ ×1.2 または倍率なし・行動キャンセルのみ）」に落とす。
  2. **カウンター割りの見返りを強化する**: 大技（またはチャージ）に合わせて割ったときだけ **被ダメ ×1.8〜2.0（または次T手札 +1 / 充電 +4 等の明確な報酬）** を与える。
  - 狙い：「1ターン火力を控えて待つ損失」を明確に上回るリターンを構造的に作り、段取りの優位を立たせる。
- **案B（敵の大技側）：大技の「素受けしたくない圧」を上げる**
  - 現行は防御カードやシールドで大技をある程度安く受け切れてしまうため、大技を消す価値が薄れている。
  - 大技に **防御貫通・シールド削り・状態異常／弱体付与** などの「防御だけでは安く済まない要素」を持たせ、「待ってでも大技を潰す」動機を強める。
- **案C（BOT側の切り分け確認・約2分で実施可能）：現行ルールのまま `downAimGainShare` を `0.2 → 0.8〜1.0` に上げて測る**
  - 「今のルールのままでも、もっと積極的に待てば勝率が上がるのか（＝BOTの割引が強すぎただけ）」、それとも「積極的に待っても勝率が上がらない／むしろ下がるのか（＝案A・Bのルール変更が必須）」を 10,000 ラン対比較で切り分ける。

- **数字が支える事実**:
  - **読む腕と近視眼の差（`S − G`）は、大技を重くすると有意に開いた**:

    - 最深部クリア率差も `H0` `+1.04 pp` → `Hh` `+1.19 pp` → `H1` `+1.38 pp`（`p=0.00501`）、ボス戦死ラン率差も `-1.22 pp` → `-1.56 pp` → `-1.76 pp`（`p=0.00545`）と段とともに拡大した。

    - `E_H0` **`51.67%`** → `E_Hh` **`49.46%`**（`-2.21 pp`）→ `E_H1` **`47.92%`**（`-3.75 pp`）。**今回測った 3 段（`H0` / `Hh` / `H1`）の中に、経験者の 3 層クリア率が 40% 前後に入る段は無かった**（`downGaugeNoAttackHold=True` 既定化により、`E_H0` は ⑮ `E_Now` の `49.39%` より高く出ている）。
