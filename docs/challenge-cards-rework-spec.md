## §0. 設計方針と絶対制約

1. **完全カード駆動（方向性 A）**：固定の基礎敵ステ補正は追加せず、難易度の上昇はすべて層入口の挑戦カードだけで表現する（暗黙補正ゼロ、`GAME.md §24` 遵守）。
2. **1 層 1 枚・最大 5 枚（2 連続引き完全廃止）**：入口 5 箇所（`開始` / `1→2` / `2→3` / `3→4` / `4→5`）で各所最大 1 回。全難易度で **左 ≤ 右（深い層ほど重い）** の完全単調増加を守る。
3. **表（純デバフ）と裏（純バフ）の完全独立**：
   - 表は 100% 純デバフ、裏は 100% 純バフとし、1 枚のカード内にバフ・デバフを混ぜたセット効果を作らない。
   - `Deal` 時に独立した表プール（別系統の 2 枚）と裏プール（2 枚）をランダムに組み合わせて「表｜裏」の 2 択を作る。
   - 同じ種類（`kind`）は 1 ラン 1 度だけ（軽い Tier で先に取って重い Tier のプールから消す戦術は据え置き）。
4. **Lv10 は特別であるべき**：
   - **Lv1〜9 は七つの大罪ナシ（Tier I〜III のみ）**。
   - **Lv10 の `4→5`（最終層入口）でのみ、七つの大罪（Tier IV・裏バフなし・とんでもない強度）が解禁**される。
   - 序盤（1〜4 層）のファーム・経済を壊す「三重の罰」を避けつつ、Lv9 を突破したプレイヤーが素通りできない明確な頂点を作る。
5. **丸め規則と最小ステータス衝突ゼロ**：
   - 敵強化・デバフの `%`：**四捨五入（`Mathf.RoundToInt`）**（現行 `Escalation.cs` 準拠）。
   - プレイヤー強化・バフの `%`：**切り上げ（`Mathf.CeilToInt`）**（現行 `CombatManager.Damage.cs` 準拠）。
   - `Assets/Resources/enemies.json` の各層最小ステータス（1層 `HP 45 / raw 3`、2層 `46 / 6`、3層 `312 / 8`、4層 `604 / 14`、5層 `3562 / 24`）に対して、**上位 Tier と下位 Tier（および未発動）が同じ整数へ潰れない**よう Tier 配置と数値を設計済み。
6. **レガシー同時掃除**：廃止する旧カード（`猫の手`・未実装 `pending: 金で殴る`・`pending: EnemyDef`・統合廃止した旧デバフ群）と、その参照・未使用定数・BOT 評価コードは同時に削除する。

## §3. 裏（純バフ）14種（新8軸 × 1 ＋ 汎用 6種）

### 3-1. 動的 4 枠ロック連動の抽選ルール
- `Deal(tier)` で裏バフ 2 枚を引く際、**死にバフ（ロック外軸のバフ）を出さない**ため以下のルールで抽選する：
  - `RunState.lockedAxes` に 1 軸以上登録されている場合：
    - **1 枚目**：`lockedAxes` に含まれる軸（所持数単独 1 位の主軸を重み ×2 で優先）の未所持軸バフから抽選（枯渇時は汎用へフォールバック）。
    - **2 枚目**：残りの `lockedAxes` 軸バフ ＋ 汎用 6 種（未所持）から抽選。
  - `lockedAxes` が空（開始時かつ種火なし）の場合：全 8 軸バフ ＋ 汎用 6 種（計 14 種）から 2 枚抽選。

## §5. レガシー掃除 ＆ 検証基準

### 5-1. 同時掃除チェックリスト
- `ChallengeCards.cs` から廃止カード（`Cat` / `GoldPunch` / `EnemyDef` / `Judge` / `Ambush` / `Rage` / `Erode` / `EnemyShield` / `WinGold` / `TermAtk` / `TermBlk` 等）および `CatPawAdvisor.cs`・`ChooseCatPaw`・`GoldPunchAttack` 等の関連フックを削除。
- `MetaDebuffApplicator.cs` / `MetaBuffApplicator.cs` から呼び出し元 0 件になったゲッターを削除。
- `PermanentDebuffIds.cs` の未使用 `shortDescriptions` / `GetShortDescription`（旧大罪効果の残骸）を掃除し、フレーバー正本＋新効果表示へ整理。
- `AutoRunner*` の挑戦カード選択・戦闘見積もり（`CatPaw` / `GoldPunch` / 旧大罪評価等）を新37種へ同期。
- 中断セーブ互換：旧セーブに未知のカードIDがあれば安全にスキップ（クラッシュ禁止）。

### 5-2. BOT 検証基準（Super・イベントあり・IL2CPP 並列ワーカー）
1. **クリア率の美しい単調階段（Lv0 → Lv5 → Lv9 → Lv10）**：
   - Lv0：ベースライン（20〜25%）
   - Lv5：~10〜14%
   - Lv9：~5〜8%
   - **Lv10：Lv9 から有意に大きく落ちる明確な壁（目安 1.5〜4%、0% にならないこと）**
2. **大罪 7 柱の個別バランス**：Lv10 で各 7 柱を強制付与（各 1,000〜2,000 runs）し、極端な即死（0%）や素通り（Lv9 と同率）になっている大罪が無いことを確認・較正する。
3. **裏バフの死に率ゼロ**：動的4枠ロック連動により、裏バフが「ロック外軸の死に札」になっていないことをログ確認する。
