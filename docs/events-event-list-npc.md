## さびれた観測所

`召喚専用,1-6層,一度のみ,優先`

　観測所と呼ぶには小さすぎる小屋に、老人が一人いる。壁一面が数字で、日付の列だけが妙に長い。百年分はあり、途中で筆跡が変わっていて、変わったあとも同じ人間の字に見えた。最後の数行は、まだ来ていない日付だった。「座りなさい」と老人は言う。「この観測所に座るのは、私は三度目でね」。

　狭間は場所と場所を繋いでいるのではない、と老人は言う。同じ場所の、進み方の違う写しを繋いでいる。遺物が別の世界から流れ込むという説明を、彼は取らない。あれは同じ世界の、もっと先まで行った写しから落ちてくる。こちらがまだ作っていない物を、向こうは既に作った。だから未解明に見えるだけだ。

　「穴が広がるのは、写しどうしの隔たりが薄くなっているからだ」。薄くなるほど物が流れ込む。流れ込むほど街は潤う。潤っているあいだ、誰も薄くなっていることに気づかない。「順序が逆なんだ。豊かになったから広がるのではない。広がっているから豊かになる。同じ数字を、あちらは繁栄と読み、私は残りと読む」

　深く降りるというのは、下へ行くことではないらしい。もっと先まで進んだ写しの側へ寄っていくことだ。だから深層では法則が通らない。あれは別の物理ではなく、もっと後の物理なのだと老人は言う。

　「そして」と老人は言い、そこで一度言葉を切った。「先へ寄った者が、元の側へ戻ろうとすると、どうなると思う」。

　その問いの意味は分からなかった。老人は答えを待たず、床の荷を足でこちらへ寄せた。まとめてあった。今日まとめたようには見えない。「持っていきなさい。私にはもう要らない」
