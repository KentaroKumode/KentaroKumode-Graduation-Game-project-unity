"背景 / 選択肢 / 影響 / 判断材料 / 暫定方針" structure and has frontmatter
with `urgency`, `blocks`, and `opened` date.

## Recently decided

When status flips to `decided`, move the file to `../adr/` (promoted)
or delete it (rejected) — don't leave stale `decided` items here.

## Format

Each file:

- **背景** — why this is open
- **選択肢** — options under consideration
- **影響** — what suffers while open
- **判断材料** — what's needed to decide
- **暫定方針** — current default behavior
- **解決時のアクション** — checklist when decided
